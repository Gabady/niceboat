## エンディングの分岐

| 結果 | 使用するエピソード |
|---|---|
| 最優秀シリーズの優勝戦で有効な1着 | 優勝のあとで |
| 最優秀シリーズの優勝戦で有効な2〜6着 | 優勝戦を終えて |
| それ以外 | 次の季節へ |

「それ以外」には予選敗退、準優勝戦、F/L、転覆・未完走、SG進出条件未達を含みます。準優勝戦1着を優勝エンドにしません。育成途中の登録では最優秀後のエンディングを作りません。

シリーズ終了時に結果・関係・本文を一度保存し、結果画面と「物語」から読めます。登録後も選手プロフィールから再読できます。未完走のヒロインを恋人扱いにしたり、出会っていない師匠を師匠扱いにしたりしません。記録を読むだけで能力・報酬・別育成の関係は変わりません。

## 優勝戦の応援

ヒロインのルートを完走し、交際を継続して最優秀シリーズの優勝戦へ進んだ場合に表示します。時計が止まっている開始前の画面に組み込み、元からある開始ボタンでそのまま走り出せます。走行中の視界・操作を覆いません。

瑞希が同じ優勝戦に出走する場合は、互いの艇へ向かう前の言葉になります。演出「短縮」は小さな表情、「なし」は静的な文章のみ。再開や再読込で同じ応援を繰り返しません。応援表示自体の追加能力補正はありません。

## なつと二人で会う条件

- G3前期〜G1前期。
- なつが登場する応援イベントで、選択肢まで終えた交流が2回以上。
- 他のヒロインと交際中・ルート完走済みではない。
- 条件成立後、レース準備ごとに専用の抽選で出会いが進展します（内部確率15%）。

同じイベントの再演も、返答まで終えれば交流に含めます。開くだけ・中断・見送りは含めません。抽選結果を保存するため、画面の再表示や連打では引き直せません。ゲーム内では細かな確率を表示せず、遊び方に条件のヒントを記載しています。

一般の応援者として接していたなつの、仕事・友人・水辺の散歩案内という暮らしを知り、二人の関係を育てる物語です。既存ヒロインと同様に好感度、お願い、友人・破局分岐、交際の制限があります。恋愛終盤のG1優勝条件も共通です。

ルート完走後にSG優勝戦へ進出すると、専用能力 **「声の帰る岸」** を獲得します。通常はLR、イージーは補助量を抑えたUR。最終周の直線で立ち上がり・姿勢・消耗を支えます。一般抽選や通常ショップには出ません。

G1前期の最終走前に解放された場合も、適切に交流を進めればSG優勝戦までに7話を完走できる日程を検証しています。必ず完走・出会いが成立する保証ではなく、選択・成績・交流によって変わります。

## 初登場・旧セーブ

初めて会話を読む時に、人物の役割と最初の挨拶を短く紹介します。紹介を読み終えた相手には別の場面で繰り返さず、途中で閉じても同じ位置から再開できます。過去の会話実績やしおりがある旧セーブでは、既存の進行を尊重します。

セーブキーは `kyotei_monogatari_v80` のままです。V125以前の能力・賞金・関係・進行中レースを維持し、なつの未発見枠を追加します。終了済みで未登録の育成は、保存されている結果から後日談を追加します。すでに登録されている過去の選手について、残っていない最終レース結果を推測してエンディングを生成することはありません。

更新前に設定画面からセーブJSONを書き出せば、別ファイルやブラウザーへ引き継げます。操作練習の履歴は育成JSONとは別保存です。
