# 競艇物語 V133

改善提案の前半5項目を実装した版です。V132のヒロイン10話・ライバル8話、回想・心の声、モーター／プロペラ整備と条件付きティルトを引き継ぎます。

## 今回の変更

1. **選択を次の出来事へ反映**：ヒロイン7人の第3話・第5話に各3つの返答を用意しました。選択を保存し、第4話・第6話に全42通りの後続場面を追加。相手から誘う、こちらから連絡する、別の場所で会う、一緒に作業するなど、その後の出来事が変わります。第8話にも選んだ言葉を反映します。この14場面の返答には、一律の不正解や好感度の優劣を設けていません。
2. **人物ごとの描写**：灯の仕事への意地、澪のドラマへの熱中、凪の競争心、奏の細かなこだわり、紬の商売と休日の迷い、瑞希の嫉妬、なつの案内役としての試行を描きました。メイン4編にも、時期ごとに異なる会話を追加しています。
3. **自動会話の配置**：長い話は、同じ到着・準備・節の帰還につき原則1本。残りは保存して、次の節目で自動発生します。レース直後は結果画面と結果に応じた短い言葉を先に表示します。出走前の短いイベント、師匠の導入の続き、優勝戦直前の第9→10話、育成終了時の未読本編は必要なタイミングで進めます。
4. **金銭による好感度イベントを廃止**：90〜110万円の品物を求めるイベントは新規発生しません。旧セーブの購入相談が返答待ちの場合も、金銭・好感度を変えずに終了します。過去に支払った金額・得た好感度・読了記録は維持し、返金や再授与はしません。交際に必要だったG1優勝条件も撤廃しました。
5. **本編固有の育成判断**：メインの返答で、次に試す準備を選びます。実際に使った練習・整備枠やレース結果で進捗を記録し、次章で達成・未達に応じて会話が変わります。読むだけでは進捗や報酬は増えません。

特訓ボタンに残っていた「好感度も上昇」も削除しました。交際条件変更に合わせて、目標表示と未完走時の説明も修正しています。

## 本編ごとの実践

|物語|方針A|方針B|
|---|---|---|
|父の工房|別々の二走で同じ部位を整備。実践中は成功した整備の仕上がりを少し補助。|モーターとプロペラを一度ずつ整備。実践中は整備経験を少し補助。|
|奏斗との分析|選択時の苦手能力を、別々の二走で練習。|ライバルと特訓し、選択時の苦手能力を自主練。|
|岸の応援|フィジカルを練習した後、有効完走。|旋回を練習した後、3着以内で有効完走。|
|折れた航跡|以前の得意能力を練習した後、有効完走。|別の軸の能力を練習した後、有効完走。|

通常の行動枠を使います。体力などの新しい管理数値は追加していません。準備画面に目標と進捗を表示し、達成は各方針の選択につき一度だけ記録します。整備経験やコツの補助は小幅にし、能力・整備力の既存上限を守ります。再起編の実践は、その日の試行であり、既存の「磨き直す／新しい主軸」の大きな方針を強制変更しません。

本編の次の選択で、新しい実践に切り替えます。直前の実践結果は章の本文へ保存されます。育成終了後の最終返答で、実行できない新しい課題を開始することはありません。未達でも物語は進みます。

## ヒロインの進行

- 第1〜7話：信頼・好感度・育成段階・待ち走数に応じて進行。
- 第8話：好感度70以上・信頼60以上などを満たし、告白を受け入れると交際。G1優勝や贈り物の購入は不要です。他の相手と交際中の場合の制限は継続します。
- 第9話：交際後の日常。G1後期以降。
- 第10話：最優秀シリーズ優勝戦へ出場する直前に解放。予選・選抜戦・出走後では解放しません。読了による完走とLR伝授を維持します。

全話が無条件に発生する仕様ではありません。出会い・関係・待ち走数・出場条件は残ります。次走の着順を約束する無料イベントも残ります。第8話の交際条件と、メイン最終章の技の伝授条件は別です。後者に必要なG1優勝などは変更していません。

## セーブ・既読・旧版からの移行

保存キーは `kyotei_monogatari_v80` のままです。能力・賞金・交際・既得報酬・登録選手・進行中レースを維持します。V130〜132の整備値を誤って70へ制限する旧移行経路も修正しました。

新しい分岐の記憶は、V133の該当場面で実際に選んだ場合だけ保存します。旧版の同じ選択番号から新しい約束を作ることはありません。保存済み本文・返答は書き換えず、未読の更新本文は別の本文版として読み始めます。既読スキップは選択肢で止まります。

持ち越した自動会話も保存されます。読んでいる途中の話は再開し、まだ始まっていない話は次の節目へ持ち越します。最優秀優勝戦の最終話は、会話数制限より優先します。

## 開き方と更新

- `index.html`：基本単体版。
- `index_android_safe.html`：Android Safe単体版。

`python3 tools/build_all.py` で全HTMLを生成し、`python3 tools/verify_all.py` で処理・CSS・素材の一致を確認します。梱包は `python3 tools/package_v133.py`。
