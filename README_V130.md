# 競艇物語 V130

ヒロイン7人を各10話、主ライバル5人を各8話に拡充し、全110話の本文・選択肢・返答をリライトしました。仕事や生活の具体的な出来事から関係を描き、交際後のすれ違いと仲直りも加えています。

## ヒロインの進行

|節目|内容と条件|
|---|---|
|第1〜7話|出会いから、仕事・過去・相手との距離を知るまで。信頼・好感度・育成段階・待ち走数に応じて進行。|
|第8話|告白への返答。受け入れると交際開始。G1前期／後期いずれかの優勝、好感度70以上、信頼60以上などが必要。友人を選ぶ／断る場合は交際せず、その恋愛ルートを終了。|
|第9話|交際後の日常。予定の食い違いや嫉妬、善意の押しつけを二人で扱う。G1後期以降。|
|第10話|最優秀シリーズの優勝戦へ出場する直前に解放。それまでの小物・会話・約束がつながる最終話。予選・選抜戦では解放しない。読了でルート完走と従来のLR伝授。|

通常は2走ごと、G2後期以降に出会った相手とは1走ごとに会えます。第10話だけは優勝戦直前の待ち走数を免除します。8話目で交際した後、優勝戦へ進めなくても交際状態と恋人の後日談は維持します。出会いや成績によっては、育成中に全話を読めない場合があります。

|人物|物語の中心|
|---|---|
|灯|父の図面と自分の仕事、県外研修、会いたい気持ち。工房の外でも会う関係へ。|
|澪|誤報と訂正の責任、取材相手との境界、担当を離れて伝える好意。|
|凪|競技を離れた記憶、看護師の仕事、自分が世話されることへの戸惑い。|
|奏|舞台で止まった経験、小さな試演会、弾かない日にも会いたい相手。|
|紬|店の移転と休日、客を待つ時間から、恋人と約束する時間へ。|
|瑞希|父の名前、古傷、競争心と嫉妬。恋人にも勝ちたい選手同士の関係。|
|なつ|応援の当番、案内会、自分の予定。旗を持っていない日の彼女を知る。|

「折れた航跡」では凪・瑞希・なつに復帰経験を踏まえた会話を追加しています。瑞希の第10話は、同じ優勝戦を走る場合と岸から応援する場合で台詞が変わります。

## ライバルの進行

晴人・蓮・泉・蒼・伊吹を各5話から8話へ拡充しました。順に新人前期、新人後期、G3前期、G3後期、G2前期、G2後期、G1前期、最優秀シリーズで進められます。第8話には親愛度60以上が必要です。

- 晴人：兄との比較、負けた日の苛立ち、練習の約束を破った後の関係。
- 蓮：図面どおりに走れない相手、失敗を消す癖、説明できない勝ち方。
- 泉：怖さを隠す声、急ぎ過ぎた励まし、怖いまま出走する選択。
- 蒼：遅く競技を始めた焦り、練習量への執着、前の職場との距離。
- 伊吹：強い人に見られる息苦しさ、接戦での怒り、生活と勝負の力加減。

技の伝授は第8話で、8回中6回以上の理解・最後の返答・一度以上の対戦先着を満たした時に一度だけ行います。親愛度の低い初期値と、意識して交流するV129の調整を維持しています。

## セーブと再読

保存キーは `kyotei_monogatari_v80` のままです。能力・賞金・機材・親愛度・獲得済みの技・進行中レースを引き継ぎます。

旧ヒロインの0〜5話読了は同じ進行位置、6話読了は新7話読了相当、7話完走は新8話読了相当へ移行します。旧版で交際していた相手・完走実績・LRの権利を維持し、追加した9・10話を進められます。挿入した話を実際に選択したことにはせず、旧選択履歴を別途保持します。登録済み選手の記録は書き換えません。

旧ライバルの読了済み本文・選択ラベル・返答を保存したまま、残りの話へ進めます。旧第5話で獲得済みの技は再授与しません。今回から読んだヒロイン会話は本文も記録に残り、選んだ返答と一緒に読み直せます。書き換わった本文は未読になり、既読スキップが選択肢を勝手に選ぶこともありません。

成長抑制、整備の2択化、ティルト／プロペラ性能値、低整備力での高性能機材の難しさ、シナリオ固有効果、横画面の小顔表示、スタート先行選択の廃止、親愛度イベント、最優秀出場賞金3,200万円、ハードのSS120・初期1.2倍・SSR1個・MLRを維持しています。詳しい数値は `README_V129.md` と `BALANCE_V129.md` にあります。

## 開き方と編集

- `index.html`：基本版。単体で開けます。
- `index_android_safe.html`：Android Safe。単体で開けます。
- `index_iphone_safe.html`：iPhone Safe。単体で開けます。
- `index_editable.html`：`src/`を参照する編集版。
- `web/index.html`：画像・音声を分離した版。`web/`全体を同じ場所に置きます。

編集元は `src/` と基本 `index.html`。今回の本文は `src/routes130.js` にあります。`python3 tools/build_all.py` で全5HTML、`python3 tools/verify_all.py` で全51モジュール・HTML・CSS・素材の一致を確認します。iPhoneの画面高追従・共有保存補助も維持しています。

## 今回の検証

V130の結果は `tests/*-v130.json`。旧番号のレポートは過去の結果です。

- `routes-v130.cjs`：全員の交際・10話目・LR・ライバル8話・親愛度条件・後日談・不正データ拒否。
- `legacy-v130.cjs`：V129実エンジンで作成した交際・選択待ち・完走・登録済みデータと、V122／123／127／128の実セーブの引き継ぎ。
- `ui-logic-v130.cjs`：実画面生成、選択前の効果防止、既読スキップ、記録再読、進捗と解放条件の表示。
- `story-integration-v130.cjs`：人物紹介、最終レースから後日談、登録後の再読、別育成への影響防止。
- `balance-v130.cjs` と `features-v130.cjs`：従来の成長・整備・親愛度・賞金ボーダー・ハード・MLRを再確認。
- `safe-sync-v130.cjs`：基本・両Safe版の配布用インラインコードで、4シナリオ×3難易度×3HTMLの36レースと保存復元を比較。
- `resume-v130.cjs`：第1〜9話の選択から予選5走を実計算し、優勝戦への進出で第10話が開くこと、出走前の保存復元と報酬の重複防止を確認。

NodeとDOMアダプターによる検証です。再開時にこれらのテストを再実行しています。実ブラウザーの起動も試しましたが、実行に必要なブラウザーがなく、ダウンロードも正常に完了しなかったため、画面配置、実機のタッチ・音声・FPSは未検証です。`python3 tools/package_v130.py` で検証済み一式を梱包します。

再開時には、交際制限の案内を「第8話」に訂正し、なつの告白台詞、晴人の練習回想、iPhone説明書と梱包の版情報を整えました。全110話の追加内容はV130として引き継いでいます。
