# 競艇物語 V125

V124までの機能・シナリオ・保存機能を引き継ぎ、基本版・Android Safe・iPhone Safe・編集用・素材分離版の全5種類を更新しています。

## 変更内容

| 項目 | 今回の変更 |
|---|---|
| 高速演出 | 重複していた水色の速度線・青い発光縁・浮遊粒を取り除き、船首から左右へ分かれる水流、後方へ流れる泡、小さな飛沫で速度を表現 |
| スタート | 通常の早発許容をA以上に限定。B以下は時刻前の通過でF、時刻ちょうどなら有効。対象特能を持つ場合は例外 |
| 能力成長 | 直線・旋回・スタート・加速・フィジカルのB以上の永久成長を鈍化。A以上はさらに小さな伸びに |
| 師匠 | 5人それぞれに「出会い」と「弟子入りの相談」を追加。主人公が教わりたい理由と、相手が引き受ける理由を描写 |
| ヒロイン | 6人全員に平静・笑顔・思案・真剣・驚き・照れの6表情を用意。本人の台詞に合わせて表示 |

高速時も前方の艇・ブイが見える中央の視界を確保しています。演出の控えめ／なし、動き停止、一時停止を保持。V124のフィジカルで軽減される視点の揺れと、姿勢による見え方の差も維持しています。

### スタートの特殊能力

「零の踏み込み」「一閃の境地」は、所持している間、能力ランクにかかわらず小さな早発の余裕を与えます。能力上昇の抽選が発動していない助走時にも有効ですが、早過ぎる通過はFです。通常の許容と特能は加算せず、もっとも大きい許容だけを使います。

従来から先行していた神楽・挺王・宿命の最終ライバルは、物語専用特能「先駆の心得」の所持による例外へ整理しました。人物名や一時的なスタート能力上昇だけでは、早発例外は発生しません。「先駆の心得」は通常抽選・ショップ・先着報酬で獲得しません。許容秒数は通常画面には表示せず、対象条件をヒントに記載しています。

### 能力成長

成長型・練習方法・各種報酬による違いは残し、高能力帯の伸びだけを抑えています。内部の基準係数は以下のとおりです。ゲーム画面では細かな係数を表示しません。

| 能力帯 | V124 | V125 |
|---|---:|---:|
| C以下 | 従来係数 | 維持 |
| B | 0.60 | 0.45 |
| A | 0.40 | 0.20 |
| S以上 | 0.16 | 0.07 |

練習・レース・物語・師弟・ライバル特訓・技能獲得などの永久成長へ共通適用します。大きな報酬で能力帯をまたいでも、境界を越えた分には次の係数を適用。端数は保存されます。**育成済みの能力を下げる変更ではありません。** 初期能力、相手選手の基礎能力、機材調整の係数は変更していません。

### 師匠との出会い

新しい育成では、G3で先輩に出会う場面を開き、続いて入門の相談を読めます。会話は行動回数を消費せず、途中で閉じても続きから読めます。入門の約束が成立すると合同練習が開きます。

早瀬・月野・久住・赤嶺・岩瀬の各分野に沿って導入を描き、既存の5話へ接続しています。師匠の抽選と、主ライバルと得意分野を重ねない条件は維持しています。既存セーブですでに割り当てられている師匠との関係は成立済みとして扱い、初対面をやり直しません。

### ヒロインの表情

汐見灯・星宮澪・花守凪・朝比奈奏・橘紬・朝凪瑞希の計36表情を内蔵しています。既存の顔立ち・髪型・衣装・背景に合わせて画像を生成し、軽量WebPのアトラスとして組み込みました。

台詞ごとの表情指定を基本に、否定や複雑な気持ちを単語だけで笑顔にしないよう整理しています。主人公や別の話者の感情はヒロインへ流用しません。ヒロイン本文・選択肢・条件・報酬は維持しています。素材と生成指示は `assets/heroine-expressions/` に同梱しています。

## 起動と引き継ぎ

| ファイル | 用途 |
|---|---|
| `index.html` | 基本版。画像・音源を内蔵 |
| `index_android_safe.html` | Android Safe版 |
| `index_iphone_safe.html` | iPhone Safe版。画面高追従・JSON共有保存補助付き |
| `index_editable.html` ＋ `src/` | 編集用。フォルダごと使用 |
| `web/index.html` ＋ `web/` | 素材分離版。フォルダ全体を配信 |

セーブキーは `kyotei_monogatari_v80` のままです。更新前に設定画面でセーブJSONを書き出すと、別のファイルやブラウザーでも引き継げます。進行中レースでは未通過のスタート目標に新ルールを適用し、通過済みのST/F/L判定は保持します。旧版の先駆NPCは記録済みの宿命ライバルを含め、対応する固有特能へ移行します。

操作練習の比較履歴は旧記録を保持し、今回の走行ルールとは条件を分けて比較します。操作練習履歴は育成セーブJSONとは別保存です。

iPhoneはSafariで配信したURLからの利用を想定します。この配布物に公開URLは付いていません。

## 検証

今回の結果は `tests/*v125*.json` に保存しています。

- スタートのA境界、時刻ちょうど、特能所持、全6コース、風条件、旧途中セーブを検証。
- 永久成長の5能力・各能力帯・境界跨ぎ・代表経路をV124と比較。
- 全5師匠の導入、無消費の入門、未入門練習拒否、中断・再開、既存ルート完走、旧セーブ保持を検証。
- 表情の話者対応、否定表現、長文分割、全ヒロイン本編・日常・復帰編・終幕、画像とセル配置を検証。
- 高速演出を実Canvasで描画し、中央視界・演出設定・状態不変・カメラ継承を確認。
- GUIのHTML生成と操作をDOM代替環境で検証し、全5HTMLの内容一致と基本・両Safe版の同条件進行を確認。

**実ブラウザーのレイアウト、Android／iPhone実機のタッチ・音・FPSは未検証です。** Canvasの画像・処理時間は開発環境での結果です。旧版の検証JSONは今回の結果とは区別してください。
