# 競艇物語 V122

V121を引き継ぎ、保存・振り返り・操作練習・中断復帰と、雨天グラフィックを改善しました。
基本版、Android Safe版、iPhone Safe版、編集用HTML、素材分離版に同じ内容を反映しています。

## 雨天グラフィック

- 晴天の青空を暗く重ねていた表現を、雨専用の曇天へ変更。
- 遠景の彩度と霞、水面への空の反射を雨天に合わせて調整。
- 遠く・中間・近くの雨粒で長さ・速度・濃さを変え、中央の艇・ブイを確認しやすく調整。
- WebGLと軽量Canvasの両方に反映。Canvasの雨背景は再利用し、再生成を抑制。
- 「控えめ」は雨粒を減らし、「追加演出なし」は雨線も停止。「視点の揺れ・雨風の動き」を止めた場合も、傷のような固定雨線を残しません。
- 雨の物理効果、能力、レース判定は従来どおりです。

## 保存と復旧

本体セーブ・直前バックアップ・保存枠・練習記録を別々に管理します。バックアップだけが失敗しても、本体の書き込みを続けます。「進行が一時保存中」と「進行は保存済み／一部の記録が未保存」を区別し、設定画面から未保存分を再試行できます。

更新前バックアップは実際の保存成功後にだけ完了を記録します。失敗した場合は次回に再試行でき、完了印だけが残って更新前データを保存できなくなる問題を修正しました。

JSONのファイル読込と貼り付けは、どちらもUTF-8で15 MBを上限にします。旧版はテキスト500万文字まで受け入れていたため、日本語を含む旧データも引き継げる大きさです。書き出しは全内容を保持したコンパクトJSONです。上限を超える例外的なデータは、コピーで退避する画面と警告を表示します。

## 結果から次の一走へ

結果画面は「着順・賞金 → 能力成長 → 振り返り」の順にしました。振り返りと育成画面の助言は共通の判定を使い、差が開いた区間、その区間の記録、リプレイ位置、操作練習を対応させます。

観戦・自動走行・途中から観戦は明記し、プレイヤー本人の操作の評価と区別します。「詳しい走行記録」は計測した事実を表示し、別の基準による追加の助言は出しません。記録だけで原因や勝利を断定しません。

## 操作練習の比較

同じ条件の前回・項目別ベストと比較できます。

| 練習 | 比較する記録 |
|---|---|
| スタート | ST（合法な早発の実測値も表示） |
| 第1ターン | 区間時間・出口速度・横滑り・接触・境界接触 |
| 引き波の脱出 | 引き波内の時間・接触・区間時間・境界接触 |

能力・技能・熟練度・機材・水面・初期配置・方針などが異なる走行は混ぜません。姿勢補助を一度でも使用した走行は、完全な手動の記録と分けます。F/L・転覆・中断・区間未達はベストから除外します。項目別ベストは複数の走行から選ぶため、一つの走行の成績とは限りません。

履歴は最大12条件、各直近3回と項目別ベストです。育成とは別のブラウザー内データとして保存し、育成の能力・行動回数・進行・乱数を変更しません。**操作練習の比較履歴は育成JSONに含まれません。**

## スマホの中断復帰

2本指の独立操作・範囲外での指離し・入力キャンセル・画面回転時の一時停止を確認しました。別アプリへの移動などで複数の中断通知が来ても、同じ中断で保存を重複させません。復帰直後に経過時間をまとめて進めず、再開ボタンから続けます。

この確認は実際の入力処理を動かすDOM代替環境でのテストです。実ブラウザー・実機のタッチ確認とは異なります。

| ファイル | 用途 |

HTMLの実行に対応したブラウザーで開いてください。iPhoneはSafariで配信したURLからの利用を想定します。この配布物に公開URLは付いていません。

セーブキーは `kyotei_monogatari_v80` のままです。更新前には設定画面からJSONを書き出してください。ファイル名や場所・ブラウザーが変わって保存領域が分かれた場合は、新しい版へ読み込みます。V121までの能力・賞金・物語・報酬条件とレース計算を引き継ぎます。

## 全HTMLを更新する手順

ユーザー指定により、今後もすべてのHTMLへ同時に反映します。

1. `src/` の処理と基本 `index.html` のHTML・CSSを変更。
2. `python3 tools/build_all.py` で5種類を生成し、内容一致を検査。
3. 関連テストを実行して、全HTMLを配布。

`tools/verify_all.py` はゲーム処理・HTML/CSS・画像・音源まで比較します。iPhone固有の補助、参照形式、スクリプト前後の改行を除き共通です。作業規則は `AGENTS.md` を参照してください。

## 検証と限界

V122の結果は `tests/*-v122.json` と `tests/verification-v122-base.json` に保存しています。全HTML一致、3単体版×4シナリオ、既存の回帰、保存先ごとの失敗・復旧、助言の一致、練習の比較、入力・中断を検証しました。

雨天は実際のCanvas描画コードを393×852と1280×720で画像化し、通常・控えめ・演出なしを確認しました。これはHUDを含むブラウザー画面ではありません。WebGL用シェーダーはMesa OpenGL ESでコンパイル・リンクを確認しました。実ブラウザーでの描画確認ではありません。

**実ブラウザーでのレイアウト、WebGLの実行、Android/iPhone実機のタッチ・音出し・FPSは未検証です。** 従来のブラウザー検証JSONは旧版の記録です。今回の検証済み範囲と混同しないでください。
