# 競艇物語 V118

恋愛完走の価値を保ち、通常の能力配布を控えめにした改修版です。V117のG1レーサー再起編、直進スタート、能力別の早発許容を引き継ぎます。

## 始め方

- Android・PC：`index.html`（単体版）。個別配布の `index_android_safe.html` も同じゲームです。
- iPhone：`index_iphone_safe.html`。配信したページのURLからSafariで開いてください。ファイルアプリのプレビューではJavaScriptが実行されない場合があります。
- 配信向け：`web/` をフォルダごと使います。画像と音源を別ファイルにし、初回に解析するHTML・JavaScriptを小さくしています。`web/index.html` だけを移動しないでください。公開URLはこの配布物には含みません。
- 更新前に旧版の「設定・セーブ」からセーブJSONを書き出してください。URLやブラウザが変わる場合は新しい版で読み込みます。
- 再起編は「選手をつくる」→「折れた航跡 — G1レーサー挫折編」。復帰シリーズから始まり、G3、G2、G1、SGへ進みます。

## 恋愛完走とLR

**第6話と第7話には、その育成でG1前期または後期シリーズを優勝した実績が必要です。** G1の予選1勝、G2優勝、他の登録選手の優勝では解除されません。

| 条件 | V118の扱い |
|---|---|
| 出会い | 既存の抽選率を維持。毎回全員に会える保証はありません |
| 第1〜5話 | 既存の段階・走数・信頼・返答条件を維持 |
| 第6話以降 | 今回のG1シリーズ優勝を追加。信頼・好感度・返答条件も必要 |
| 最終話 | 好感度70など既存条件を維持。1育成で完走できる相手は1人 |
| LRの約束 | 全7話を完走して交際が成立し、SG優勝戦へ進出した出走前に1回。イージーの報酬置換は従来どおり |
| 遅い出会い | G2後期以降の出会いでは、次の会話まで序盤1走・後半2走に短縮 |
| 未完走 | 育成終了時に出会いの記録を残す。後日談による完走・交際・能力獲得はありません |

遅く出会った場合は、残りの最大走数でも最終話に届かない見込みを表示します。表示は予選敗退を含まない上限の目安で、完走を保証しません。G1優勝後にも交流する時間を残す必要があります。

すでに取得した能力・完走済みルートは維持します。V117以前のセーブで第6話を開いていた、または第6話以降を進めていた人物は、進行中の約束を取り消さないためG1追加条件の対象外です。旧セーブの未開放ルートには新条件が適用されます。

## 特殊能力の配布調整

| 入手経路 | 変更前 → V118 |
|---|---|
| 通常レースの有効1着 | 22% → 16% |
| SG以外のシリーズ優勝 | 85% → 70% |
| 日常イベントの伝授 | 同シリーズ内で最大1回。別シリーズで再び取得可能 |
| 通常ショップの新規在庫 | 基準価格の1.12倍。生成済み在庫は変更しません |
| 新規育成の本編完結報酬 | 対話条件に加え、今回のG1優勝と技を1系統以上開花したことが必要 |
| 本編の各返答による成長 | 両方の方針で成長。基礎加算を0.32から0.16へ調整 |

SG優勝の能力報酬100%、前哨の壁・師匠・ライバル・最終決戦の撃破報酬、登録前ラストショップは従来どおりです。敵の能力そのものは弱体化していません。既得能力の削除や習熟の巻き戻しはしません。

## 育成・物語

- 4本編の選択肢を、どちらにも目的のある育成方針に改稿。選んだ能力軸が少し育ち、次の章で返答を振り返ります。旧育成の確定済み本文・選択結果は維持します。
- 直近の公式レースでのF/L、未完走、接触、有効1着などをシリーズ後の本編に反映。発生していない事故や医学的な回復を結果から推測しません。
- ヒロイン6人・師匠5人・主ライバル5人の中盤に、その人物の仕事、日常、競争心を描く場面を追加。
- 再起編の凪・瑞希・赤嶺の専用会話を維持。主人公と同じ経験だと決めつけず、競技・負傷・復帰の違いを描きます。
- 再起編では「以前の武器」を選択。G2から同じ軸を磨き直す／別の技術で組み直す方針を固定できます。対応課題を3走で達成すると技のコツ+0.75。追加の特殊能力は配りません。
- 贈り物は購入、見送り、練習枠を1回使って協力の3択。購入は好感度+10、協力は基本+6（追加行動の効果50%時は半分）。見送りで好感度は下がりません。引き受けた着順の約束を達成できなかった場合の既存の扱いは維持します。
- 師匠の得意課題を満たして有効完走すると、着順に応じた交流に技術面の評価を加えます。

## 実践課題

説明と実走の記録を合わせました。F/L・転覆・未完走では課題達成になりません。

| 系統 | 達成の目安 |
|---|---|
| 直線 | 直線で伏せ、横滑りを抑えて8秒以上 |
| 旋回 | ターンで起こし、艇を安定させて5秒以上。境界接触1回以内 |
| スタート | 有効スタートで実通過時刻0.25秒以内。許容内の早発も対象 |
| 加速 | ターンを出て3秒以内に1.5m/s以上再加速する場面を2回。接触・境界接触なしでつなぐ |
| フィジカル | 風速5以上または引き波の中で6秒以上安定。立て直しなし |

課題達成で実践+0.8、それ以外の有効完走は+0.25。未練習の系統には実践を加算しません。コツと実践が必要な基本習得・技の開花の仕組みは維持します。

## スタートと操作

- 全艇、船首がスタートラインを越えるまで直進固定。通過の次の物理更新から操舵できます。
- 通常の早発許容は基礎スタート能力×0.002秒、最大0.20秒。能力50なら0.10秒、S100なら0.20秒。一時的な装備・技能補正では広がりません。
- 神楽瞬、挺王、最終決戦ライバルのNPCは0.30秒特例。専用アクセル制御で毎走0.30秒前の通過を狙います。
- ST表示は「秒:百分の一秒」。最速は `00:00`。内部の実通過時刻でFを判定し、許容を超えるとFになります。
- 出走前に「余裕を持つ」「先行を狙う」を選択。時計の発進目安と観戦時の操船に反映します。手動の発進はプレイヤー自身が行います。
- ライン通過前は時計と直進案内を優先。ターン中は姿勢操作を強調し、能力カットインと人物の短い会話が重ならないようにしました。

## 練習・振り返り・演出

タイトルや育成画面から、スタート・第1ターン・引き波脱出の短い操作練習を選べます。育成中の能力・技能を使いますが、成績・賞金・好感度・技の成長・セーブの進行には影響しません。同じ条件ですぐ再挑戦できます。

レース結果は、できたこと／確かめたい場面／次の一手を先に表示します。1周を4区間に分けた順位、平均速度、横滑りを確認でき、目立った順位変化の場面へリプレイを移せます。記録のない旧レースは既存の振り返りを使います。

育成画面には現在の目標と残り行動をまとめました。登録選手の歩みから、SG制覇、5系統の主軸、再起の課題達成を記録します。この目標集に能力加算の報酬はありません。

相馬・凪・瑞希・赤嶺には通常／考え込む／笑顔の3表情を追加。全体音量に加え、BGM・効果音・エンジン音を個別に調整できます。初回は音OFFです。

## 検証と実行環境

- 自動回帰85項目：早発境界、強敵の48条件、G1解放、伝授上限、セーブ移行、各本編、実践記録など。
- 6ヒロインで、G1優勝前に終盤が止まり、条件達成後に完走できる経路を確認。出会いを固定した条件確認であり、自然プレイでの完走率ではありません。
- 5能力型×2水面×2コースの20レースを比較。すべて有効完走。固定条件の自動操船では直線型が有利でした。人間の手動操作や全技能構成の勝率は未測定のため、相性を均一化する物理補正は加えていません。
- Chromiumの390px（編集版）、360px（Android単体版）、393px（iPhone単体版）、1280px（素材分離版）で会話、練習、音量保存、操船開始、再読込、結果とリプレイを確認。
- 単体版と素材分離版で、BGM再生開始と6種の効果音デコードを確認。素材分離版のタイトル初回読み込みは、このローカル確認で約2.04MB（単体版約46.63MB）。全素材の合計は約33.72MBで、総容量を削除した版ではありません。
- Safari/iPhone・Android実機のFPS、タッチ感度、音出しは未確認です。

結果は `tests/verification-v118*.json`、`tests/balance-v118.json`、`tests/browser-verification-v118*.json` に収録しています。

## 編集する場合

1. `python3 tools/extract_source.py` で `src/` と `index_editable.html` を取り出します。既存srcは上書きしません。
2. JavaScriptを編集後、`python3 tools/rebuild.py` で単体HTMLへ反映します。CSSの変更は単体HTMLにも反映してください。
3. `python3 tools/rebuild_web.py` で `web/` を単体版と同じ内容に更新します。

通常テストはNode.jsで実行します。V117との比較テストはV117のソースが必要です。旧版を `v117-backup/` へ展開し、その中で `python3 tools/extract_source.py` を実行して旧srcを用意してください。ブラウザーテストにはPlaywrightとChromium、必要なら日本語フォントを用意してください。配布物は外部の解析サービスや新たな通信先を追加していません。
