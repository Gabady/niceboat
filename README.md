# 競艇物語 v103

選手を育て、3周の水面を操船し、最高峰へ挑むスマホ向けゲームです。

## 今回の変更

- 全94スキル名を見直し、57種を改名しました。冗談調の表現を改め、全スキル名から句読点・区切り記号を除いています。所持ID・レア度・効果量は維持します。
- 左下の操作を上下にも拡張。左右で舵、下で伏せて直線の伸び、上で起こして旋回の収まりを補います。右下の広いアクセル判定はそのままです。
- 姿勢は指を離しても保持し、切り替え速度には旋回・フィジカルと走行中の負荷が影響します。現在の姿勢と目標位置を小型表示します。
- 一時停止画面に「姿勢を自動で補助」を追加。上下に操作すると手動へ戻ります。NPC・観戦・スキップも同じ姿勢の物理を使用します。
- 視点とレーサーの体勢が連動。揺れOFFでは視点の高さを固定し、リザルトには姿勢の改善ヒントを追加しています。

名前の全対応は `SKILL_NAMES.md`、操作と仕様は `POSTURE_CONTROL.md`、変更理由は `CHANGES_AT.md` の @247〜254。Android／iPhone単体HTMLは画像・音込みでそれぞれ約32.1MBです。

v102のランダムなヒロイン出会い、最終話の1人制限、終盤3走待ち、短縮アイテムを継承しています。人物画像27枚、師匠25話、恋愛35話・SGイベント5本・通常物語123件も維持。イージーの新規スキルはURまで、ノーマルの専用報酬はLRです。

5曲のMP3を継承。Android／iPhone単体HTMLは画像・音込みでそれぞれ約32.1MBです。詳細は `RELATIONSHIPS.md`、変更理由は `CHANGES_AT.md` の @239～246。

ヒロインの最終話を完走し、交際中にSG優勝戦へ出場すると専用イベントと報酬があります。イージーは専用UR、ノーマルはLRです。旧版ですでに成立した交際にも従来の報酬条件を維持します。恋愛35話・SGイベント5本・通常物語123件、能力図鑑94種を搭載しています。

G3の紹介画面で師匠を選び、「師匠の物語」から個別ルートへ。続きは2走以上空け、各グレードで解放されます。第5話で一度だけ既存のLR／URを伝授します。顔の対応は `PORTRAITS.md`、師匠全文と報酬表は `MENTOR_ROUTES.md`。

5曲のMP3と場面切替も内蔵。右上「♪ 音 OFF」で開始し、♫でBGM・効果音・音量を設定します。アプリ復帰後はタップで再開。未完成のSGレース2曲は既存曲で代用でき、後から追加可能です。詳しくは `MUSIC.md`。

## 起動

- Android：`index_android_safe.html` をJavaScriptを実行できるブラウザ／HTMLビューアで開く。
- iPhone：`index_iphone_safe.html`。Safariでは配信したWebページのURLから開く方法が確実です。ファイルアプリのプレビューだけでは実行できない場合があります。詳しくは `IPHONE_README.md`。
- パソコン／分割版：ファイルの配置を保ち `index.html` を開く。

外部ライブラリ・ゲーム中の追加通信は不要です。CSS、画像、JS、音は単体HTMLに内蔵。端末や開き方によって保存領域が変わるため、更新前は設定からJSONを書き出してください。

## 既存GUIの操作

1. ホームの選手カードの鉛筆、または「選手」→「編集」でプロフィールを変更します。名前16文字、出身地16文字、ひと言32文字まで。出走中の選手はレース後に編集できます。
2. 「登録選手」で星を押すとお気に入りに。検索は名前・出身地・ひと言が対象です。
3. 人気が増えるとピットで出会う話が変わります。人気の目安は0／25／70／140／250／400。高人気が直接速度を増やすことはありません。
4. 連続イベントの続きは次のシリーズ以降の抽選です。最初の選択を記憶し、その後の本文と選択効果が変わります。毎回全ての話が出るわけではありません。
5. 下部の「物語」で記録を振り返ります。「設定」で文字とコントラストを変更。音は右上の♪でミュート・音量・BGM・効果音を設定できます。

プロフィールは装いの設定です。能力・難易度・賞金・選手IDは変化しません。レースの艇番色も維持します。既に確定したレースやリプレイの名前は当時の記録として残ります。

## 遊び方

新規作成でイージー／ノーマルを選び、名前と初期能力を決めます。イージーは勝ちやすく成長と高レア報酬は控えめ。ノーマルは強い相手と大きな成長を目指します。

新人前期・後期 → G3前期・後期 → G2前期・後期 → G1前期・後期 → SGの9シリーズ。20人で予選5走、上位6人が優勝戦、7〜12位が準優勝戦。G1後期終了時の累計獲得賞金1,800万円がSG条件です。

各走の前に通常は練習1回＋モーターまたはプロペラ調整1回。成長型の矢印を見ながら育て、機材の性格と調整方向、ティルトで走りを作ります。特殊能力による追加行動は効果50%。能力値が高いほど伸びにくくなります。

操船は左下半分で左右に舵、上下に姿勢を操作。直線では下に伏せ、旋回前は上に起こします。右下半分を押し続けて加速し、離すと自然減速。PCは左右矢印またはA／Dで舵、上下矢印で姿勢、WまたはSpaceで加速します。12秒針が頂点に来る時刻がスタートで、0.09秒までの早発を許容します。反時計回り3周、ターンでは滑り・水・接触を読みます。時計上の目安はスタート能力が高いほど確かになります。

予選は操船・観戦・結果へスキップから選択。観戦から途中で操船へ切り替えられます。優勝戦と準優勝戦は操船必須です。結果には改善のヒントと簡易リプレイを用意しています。

G3から師匠を選択。G1以降は師匠との対決、SGには最強の壁が登場。ライバル対決は有効完走して先着すると報酬があります。登録選手・記憶ライバルはSG優勝戦への特別参戦枠を持ちます。

N〜LRの特殊能力、弱点の獲得／克服、妨害・反射、連携を搭載。G3以降のショップ、登録前の限定ショップでビルドを補えます。作成選手6人の簡易レースと仮想コイン応援も遊べます。現金購入や舟券モードはありません。

## セーブ

自動保存、3つの保存枠、更新前／上書き前バックアップ、JSON書き出し・読み込みがあります。v102以前から育成・機材・賞金・走行位置を引き継ぎます。姿勢と目標位置・補助設定も保存します。ヒロインの抽選状態・終了理由・短縮アイテムの使用状況も保存します。localStorageが使えないときは一時保存で継続し、画面に通知します。終了前にJSONを保存してください。

音設定と描画・操作の端末設定は従来どおり端末側に保持されます。文字／コントラストとプロフィール・物語はセーブJSONにも含みます。

## 確認と限界

出会い抽選だけを各条件2万回、計4万育成分検証。各シリーズ5〜6走・全9シリーズ到達を仮定すると、G1後期終了までに誰かと出会う割合は約49〜55%、最後まで誰にも出会わない割合は約34〜41%でした。実プレイヤーの到達率・交際率を示す数字ではありません。詳細は `BALANCE_REPORT.md`。

MP3の場面選択・一重再生・ミュート・復帰も確認しています。Android/iPhone実機での音出しは未確認です。

自動検証262項目の結果は `tests/release-v103-verification.json` に集約。恋愛全ルートと失敗分岐、交流間隔、特訓、難易度別のSG報酬・師匠伝授と重複防止、旧保存移行、実走の能力発動、既存の育成・操作・単体HTMLの一致を確認しています。

画面操作試験は本番JSをDOM/API代替環境で実行したものです。実ブラウザのレイアウト、Android／iPhone実機の表示・タッチ・FPSは未検証です。描画の素材と水面表現は継承し、姿勢に応じたレーサーと視点を追加しています。v97の確認画像8枚は描画エンジンの出力で、今回のGUIや実機のスクリーンショットではありません。`previews/v101-portraits.png` は同梱の画像27枚を並べた確認用一覧です。人物ごとに1枚の固定画像を使用します。

走行中の折りたたみデバッグには姿勢の現在値・目標値・速度／グリップ補正、内部補正・発動・指示・カットイン件数、整備には増減前後を表示。GUIは狭幅320px、文字大きめ、長い選手名、編集キーボード、iPhoneのセーフエリアを実機で確認してください。

## 次に見るポイント

- 実機で左右の舵と上下の姿勢を意図どおり操作できるか。姿勢補助の利用率と手動の負担。
- 全開旋回に対して姿勢だけが万能にならず、減速・旋回・フィジカル・ティルトの役割が残るか。
- 出会いの希少さと、発見時期ごとのルート完走率。遅く出会った相手は残り走数で完結できない場合があります。
- 終了選択・最終話ロック・待ち時間の表示が伝わるか。短縮アイテムが購入・使用しやすいか。
- 師匠ルートを始める時期と完結率、ヒロインとの会話を並行して楽しめるか。
- 人物画像の初回表示時間と、単体HTMLを開く際のメモリ。
- 人気帯ごとのイベント出現数と、連続物語の完結率。後半の人気だけで報酬が膨らまないか。
- 1シリーズあたりのイベント成長と支援金。通常練習・ショップの役割を侵食しないか。
- イージー／ノーマルのG3以降の勝率とSG最終戦の接戦率。
- 大きめ文字での編集／名鑑の読みやすさ、ボタンの押しやすさ、必要情報までの手数。
