# V141から引き継いだ機能

V140を基に、改善案の「3：振り返り → 練習 → 次走のつながり」（19〜24）を実装しました。既存のハード調整・CPUスタート制限・MLR調整と、簡潔なUIを引き継ぎます。

## 追加した流れ

1. 結果画面の「走行の振り返り」で、次に確かめたい課題を決めます。「次走の準備へ引き継ぐ」を押すだけでは行動回数を使いません。
2. 次の準備で対応する練習・整備に「課題」の印を表示。通常の行動回数を使って試すか、そのまま出走するかを選べます。
3. 次走後に、選んだ課題に対応するST・横滑り割合・引き波割合・接触回数・再加速回数のいずれかを比較。能力と機材、実際に試した準備、操作方式も確認できます。水面・コースが違うこと、操作方式の混在、未完走は明示し、練習だけの効果と断定しません。

## 前走に近い条件で再練習

「走行の振り返り → 前走に近い条件で再練習」から、前走の能力・技能・機材・水面・進入コースを使う短区間へ。リプレイに残った問題区間の少し前の艇位置・向き・速度を再構成し、引き波の跡も近い時点から作り直します。

- リプレイは完全な物理状態を保存していないため、負荷・疲労・発動中の一時効果などはリセットされます。完全な巻き戻しではありません。
- F・Lや区間記録の不足時は、その装備・水面の助走から再練習します。
- 同じ初期条件ですぐ再挑戦できます。旧版の物理規則が付いた走行は、その規則も保持します。
- 本編の賞金・能力・成績・好感度・乱数・行動回数は変えません。途中で操作設定を変更した練習は同条件比較から外します。
- 比較記録は最大12条件・各3回＋項目別ベスト。旧記録を保持し、操作設定を含む新条件版6とは分けます。比較記録は育成JSONとは別のブラウザー保存です。

## 相手の攻略・レース中の表示

出走表の「次走の見立て → 強敵の武器と攻略の手がかり」で、実際のコース位置、雨風、所持能力、自分の得意能力に応じたヒントを表示。序盤型・全速旋回・引き波・妨害などにはそれに対応した準備の手がかりを加えます。

操船中は既存の実況欄に能力発動・引き波への出入り・接触を短く表示。観戦でも次の進行時に直近の出来事を短く確認できます。追加の大きな常設パネルは置きません。

## 育成中心モード・成績

育成開始時、または「設定 → レース・操作 → レースの楽しみ方」で切り替えます。

- 操船中心：従来どおり決勝・準優勝戦は手動。
- 育成中心：最優秀を含む全レースで観戦・結果スキップを選択可能。手動も選べます。
- 選択だけではCPU・能力・成長・報酬を変更しません。走行中に変えた設定は次走から反映します。
- 実際の操作をカウントし、手動／観戦・自動／途中切替の混在／方式不明を分けて記録。結果と選手の経歴から確認できます。手動完走後の残りCPUの結果計算は観戦へ数えません。

## 操作入門・カスタマイズ

「操作練習 → 3つの操作を体験」から、スタート → ターン → 引き波を順に体験できます。クリアした段階を保存。F・L、転覆、未達のまま次をクリア扱いにしません。ターンは接触なし、引き波は接触なしで引き波内の時間を30%以内（最低1秒の余裕）に抑える課題です。固定の練習用選手で試し、本編の能力や報酬には影響しません。

設定およびレースの一時停止中に、舵とアクセルの左右交換、大きさ、上下・左右位置、感度を調整できます。舵は「ドラッグ／左・中央・右をタップして保持」、加速は「押している間／タップで入・切」を選択可能。一時停止・画面離脱・向き変更では舵と加速を解除します。練習内での変更はその練習のみに適用し、本編用は設定画面で保存します。

# V137から引き継いだ仕様・過去の検証記録

## CPUのスタート調整

|CPUの条件|スタート時の扱い|
|---|---|
|スタートA以下・対象能力なし|初動の推力補正を抑え、能力への一時的な上乗せが重なっても強い踏み込みを解禁しない|
