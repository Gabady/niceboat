# 競艇物語 V114

曲が切り替わったとき、曲名だけを画面左上に約4秒表示するようにしました。

## 今回の変更

- 「レース」「BGM」などを付けず、曲名のみ表示します。
- レース中は速度表示の下、12秒針の左側に配置。通知はタッチを遮りません。
- 同じ曲の画面更新やミュート解除では繰り返しません。ミュート中は表示しません。

使い方は V114_GUIDE.md、変更理由は CHANGES_AT.md **@323〜324**。V113分割版には小容量の kyotei_monogatari_v114_patch.zip を上書きできます。

## 起動

- Android：`index_android_safe.html` をJavaScriptが動くブラウザ／HTMLビューアで開きます。
- iPhone：`index_iphone_safe.html`。Safariでは配信したページのURLから開いてください。ファイルアプリのプレビューでは実行できない場合があります。`IPHONE_README.md` も参照。
- パソコン・分割版：フォルダの配置を保ち `index.html` を開きます。

外部ライブラリやプレイ中の追加通信は不要。単体HTMLにはCSS・JS・画像・音を内蔵しています。今回の配布はファイルで、Web公開は行っていません。

## 遊び方

1. 名前と難易度を選びデビュー。物語の出発点はここで抽選され、以後固定されます。
2. 新人前期・後期 → G3前期・後期 → G2前期・後期 → G1前期・後期 → SG。20人で予選5走、上位6人が優勝戦、7〜12位が準優勝戦。G1後期の累計賞金1,800万円がSG条件です。
3. 各走の前に練習1回と、モーターまたはプロペラ調整1回。自主練・師匠合同・主ライバル特訓は同じ練習枠を使います。追加行動は成長・効果が半分です。
4. 育成イベントの通知から人物と話します。本文をタップして進み、最後に返答を選びます。閉じても続きから読めます。成長は選択と条件によって変わります。
5. 左下半分で左右に舵。姿勢は3つのボタンか上下スワイプ。直線は伏せ、旋回は起こす。右下半分を押し続けて加速し、離すと自然減速します。
6. 12秒針の頂点でスタート。通常は0.09秒までの早発を許容。神楽 瞬だけは固有特性で約0.20秒先行します。反時計回りに3周し、ブイの外を通ります。
7. 予選は操船・観戦・即結果から選択。観戦から途中で操船へ戻れます。優勝戦・準優勝戦は操船必須です。

PCは ←→／A D が舵、↑↓で姿勢を1段ずつ、W／Spaceで加速、Escで一時停止。姿勢補助は一時停止メニューから設定できます。

G3から師匠、G1以降は師匠との対決、SGでは最強の壁が登場。ヒロインは低確率で出会い、交流と選択で関係が進みます。イージーの新規能力獲得はURまでです。

「技の成長」では練習と実践から技を習得し、G2以降に開花先を選べます。開花は1育成2系統まで。「物語の記録」から本編・日常・主ライバル、「師匠との記録」から師匠の対話を読み返せます。再読で報酬は増えません。

音は♪でON・OFFと音量を設定。提供されたMP3 7曲を場面に合わせて切り替えます。最優秀シリーズの通常レースは「決戦前夜」、優勝戦は「最終決戦」です。

## 更新・保存

更新前に設定からセーブJSONを書き出してください。自動保存、3つの保存枠、更新前バックアップ、JSON書き出し・読み込みを利用できます。localStorageが使えない場合は一時保存となり通知します。

旧版で取得済みの能力、所持品、恋愛、途中レースは維持します。過去の本編は旧文章のまま残し、その先の章はV106以降の形式で進みます。V107以前からの更新では、過去の対話・特訓・先着記録から初期好感度を補います。V109で改稿された会話の読書位置をV114でも維持します。既に開いている最終話と取得済み報酬は維持します。

「選手」からリネームとプロフィール変更、「設定」から文字・コントラスト・保存。登録後も、その選手が実際に経験した会話と育成記録を読めます。

## ファイル構成

- `index.html`、5本のCSS：画面・会話UI。
- `data.js`、`script.js`：基本データ・育成・保存・UI。
- `affinity.js`：好感度、最終話の解放、章ごとのお願い抽選、支払いとレース後判定。
- `drama-data.js`：現在の本編・師匠・主ライバル・日常の本文と選択データ。
- `drama.js`：物語分岐・選択条件・成長機会の判定。UIとは分離。
- `development.js`、`dialogue.js`：練習、主ライバル、技の開花、本文分割、読書位置。
- `campaign-data.js`、`campaign.js`：旧本編の保存互換と新本編への接続。
- `story.js`、`story-extra.js`、`bonds-data.js`、`bonds.js`、`mentor-data.js`、`cast.js`：イベント・恋愛・師匠・ボス。
- `finale.js`：前哨突破、最終6艇、主ライバルの成長・対決／共闘分岐。
- `race-dialogue.js`：人物別セリフ、表示優先度とクールダウン。計算の乱数を使いません。
- `racing.js`、`race-renderer.js`、`driving-ui.js`、`race-feedback.js`：計算・描画・操作・分析。
- `profile.js`、`portraits.js`、`portrait-assets.js`、`assets/`：選手・人物・背景・音源。
- 音・演出用JS：`music.js`、`audio.js`、`audio-assets.js`、`presentation.js`、`thrill.js`、`visual-assets.js`。
- `index_android_safe.html`、`index_iphone_safe.html`：配布用単体HTML。
- `iphone-compat.js`、`iphone.css`：iPhone用補助。
- `tools/dialogue-v110.txt`：改稿した本文の編集元。`tools/apply-dialogue-v110.cjs`：本文の組み込み。`tools/package.py`：単体HTMLとZIPの生成。
- `tests/`：検証・固定データ・過去版の記録。`previews/`：確認画像。

## 確認と拡張

集計は `tests/release-v114-verification.json`、検証範囲と調整指標は `BALANCE_REPORT.md`。実Chromiumのスマホ幅で7曲の実再生と曲名通知、ミュート、会話の終了、レース中の配置を、分割版と両単体HTMLで確認しています。Android／iPhone実機とSafariでの今回の動作は未確認です。

レース一時停止内のデバッグで舵・姿勢・技能発動を確認できます。追加された固有特性も一時停止内で確認できます。今後は対戦ごとの終幕会話、交際後の遠征生活、場面別の音楽演出を拡張できます。調整では前哨突破率、決戦のタイム差、接触・転覆頻度、ライバル分岐の選択率を見ます。

素材は `THIRD_PARTY_NOTICES.txt`、人物画像は `PORTRAITS.md`、音源は `MUSIC.md` を参照。V114でassets/内の画像・音源の変更はありません。分割版はZIPの一式へ更新すると取り違えを防げます。単体HTMLはファイルを差し替えます。
