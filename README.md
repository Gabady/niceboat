# 競艇物語 v89 — 育成 × 一人称ボートレース

選手を育て、6艇で600mのコースを反時計回りに3周するスマホ縦画面向けゲームです。一人称で操船する方法と、同じ走行計算をAIへ任せる観戦モードを選べます。外部ライブラリ・通信・音声・課金は使いません。

## 起動

- Android：`index_android_safe.html` をJavaScriptが動くブラウザ／HTML実行環境で開きます。
- iPhone：`index_iphone_safe.html` を使用。SafariではWebサーバーに置いたURLから開きます。詳細は `IPHONE_README.md`。
- PC／Web公開：ZIPを解凍し、同じフォルダの `index.html` を開きます。

単体版には全CSS・JavaScriptを埋め込んでいます。ファイルアプリやチャット内プレビューでJavaScriptが許可されない場合、その画面だけでは遊べません。WebGLが動かない場合はCanvas 2Dの軽量な一人称表示に切り替えます。Android／iPhoneの実機プレイは未検証です。

## 操作

1. 名前・初期能力・成長型・イージー／ノーマルを選んでデビュー。
2. シリーズへ参加。各レース前に**練習1回＋調整1回**を実行できます。調整はモーターとプロペラのどちらかを選びます。
3. 「得意を伸ばす」／「苦手を補う」、調整方向、出走前のティルトを選びます。
4. 「自分で操船する」か「観戦モードで進める」を選びます。
5. 操船開始で12秒の助走。4〜6コースは後方から。時計の色帯を発進の参考にし、針が頂点へ戻るタイミングで船首をスタートラインに合わせます。
6. 左下半分から左右ドラッグでステア、右下半分を押して加速。ボタン外でも反応します。右から触り始めた指が中央を越えてもアクセルの担当は変わりません。
7. 内側ブイの外を3周し、結果を確認して次走へ。

| 操作 | スマホ | PC |
|---|---|---|
| 操舵 | 画面左側・下半分から左右ドラッグ | ← → / A D |
| 加速 | 画面右側・下半分を押す | ↑ / W |
| 減速 | 加速の指を離す | ↑ / Wを離す |
| 一時停止 | 右上のⅡ | Esc |

ボタンやスライダーの見た目は維持。見た目のステアが右側へはみ出す部分も、操作は右下ならアクセルです。アクセル受付中はボタンが点灯します。指を離す・キャンセル・画面切替・一時停止で入力を解除します。

全開中は旋回でも速度を維持し、ブレーキはありません。曲がる前にアクセルを抜いて減速します。丸いノブは実際の舵、細い印は指の指定位置。水圧による負荷があり、低旋回では低速でも舵が重くなります。低フィジカルでは接触で押し負け、ターンで外へ流れやすくなります。

## 12秒針とスタート

時計を画面右上のミニマップ位置へ移しました。助走中はミニマップを一時的に隠し、水面のスタートライン付近を空けます。発進目安の文章は廃止し、時計上の色帯で示します。

色帯は「全開を始める目安」です。低スタートでは帯が広く、推定位置も曖昧。高スタートでは狭く正確になります。幅は猶予時間そのものではなく予測の粗さです。再読み込みで読み誤差は引き直しません。時計の頂点が0秒です。

**Fは0.09秒を超えて早い通過、Lは1.5秒以上の遅れ。** ちょうど−0.09秒は許容します。実競技とは異なるゲーム用設定です。許容内の早いSTは「0.05秒早い（許容内）」と表示します。F/Lはそのレースの賞金・ポイントが0になります。

## 成長と練習

通常画面では方式の違いと各能力のおすすめだけを表示します。以下の倍率は開発・検証用の詳細です。計算自体はv88から変更していません。

シーズンに応じた成長減衰を廃止。練習・レース後の基礎成長を1.5倍にし、行動／成長処理前の能力値のランクで減衰します。既存の非SG倍率・成長型・難易度・育成能力などは別に乗算します。

| ランク | 能力値 | 成長率 | 元成長1.5倍と合わせた倍率 |
|---|---:|---:|---:|
| E | 0〜34 | 100% | 1.50 |
| D | 35〜49 | 90% | 1.35 |
| C | 50〜64 | 80% | 1.20 |
| B | 65〜79 | 70% | 1.05 |
| A | 80〜89 | 50% | 0.75 |
| S | 90〜100 | 20% | 0.30 |

- **得意を伸ばす（旧・特化練習）**：成長型の得意／苦手倍率×1.10を使用。得意能力を伸ばす用途。
- **苦手を補う（旧・基礎練習）**：選択した能力が自分の5能力平均より低ければ1.30倍、平均以上なら0.80倍。成長型倍率を置き換え、苦手を補う用途。

通常練習は固定の次走補正を付けません。所持する次走専用能力の最上位1つを、そのレース前の最初の練習で一度だけ抽選します。追加練習で抽選を繰り返せません。能力による追加枠は成長・次走補正が50%、購入券は通常効果です。通常枠を先に消費します。

## 整備の成功率と機材

新規選手の調整成功率はモーター・プロペラごとに18〜22%。成功・失敗にかかわらず、その対象の成功率が伸びます。

| 実行前の成功率パラメータ | 通常1回の基礎上昇幅 |
|---|---:|
| 50未満 | ＋4ポイント |
| 50〜59 | ＋1.8ポイント |
| 60〜69 | ＋0.72ポイント |
| 70以上 | 上昇なし |

イージーはこの学習量75%、特殊能力の追加枠はさらに50%。基礎成功率は70が上限です。整備能力は実際の成功率を加算でき、合計上限92%。旧選手の成功率は70を超える分だけ70へ移行し、それ以下の値は維持します。新規選手のように20へ戻しません。

成功率が高いほど成功時の増加を大きく、失敗時の損失を小さくしています。大失敗／失敗／微成功／成功／大成功の5段階は維持。同じ機材の連続調整は**ムラ能力の成長だけ**100→55→22%へ減衰し、成功率の学習は継続します。練習で連続状態をリセットします。

機材には抽選時から性格があります。追加の隠し補正ではなく、表示する性能値へ反映します。

| モーター | プロペラ | 性格 |
|---|---|---|
| 均衡型 | 均衡型 | 標準 |
| 伸び型 | 旋回型 | 主能力を強め、加速・状態を少し犠牲にする |
| 出足型 | 立ち上がり型 | 加速を強め、主能力を少し犠牲にする |
| 安定型 | 安定型 | 状態を良くし、主能力・加速を少し抑える |

| 調整方向 | 成功時の交換条件 |
|---|---|
| 均衡 | 主能力と加速を少しずつ上げる |
| 伸び／旋回 | 主能力を上げ、加速を少し下げる |
| 加速 | 加速を上げ、主能力を少し下げる |
| 安定 | コンディションを大きく上げ、主能力と加速を少し下げる |

安定調整はコンディション改善を通じて機材本来の出力・旋回性能を取り戻すものです。艇の横滑りを直接抑える設定はティルトです。ティルトは高角ほど速く不安定、低角ほど遅く安定。−0.5／0／＋0.5／＋1.5／＋3°から無料で選べます。

## 特殊能力と操作

新たに次の3能力を追加しました。プレイヤーもNPCも同じ操作条件を使用します。

| レア度・能力 | 条件と効果 |
|---|---|
| N：抜きの手ほどき | ターン中にアクセルを抜き、実際の舵を切って0.4秒保つ。各周1回、確定発動で2秒間の横滑り収束を助ける。 |
| R：舵戻しの基本 | ターン出口で実際の舵を中央に戻し、全開を0.4秒保つ。各周1回、確定発動で3秒間のエンジン応答改善。 |
| SR：引き波の抜け道 | 引き波を受けた後、進路を変えて抜ける。各周1回65%で、4秒間の再加速・波耐性を強化。 |

低レア2種には、条件を満たせば確定発動する固有の役割を設けました。N/Rでも高レアの単なる下位互換ではありません。元の妨害・防御・反射、洞口スペシャル、モンキーターン系、5つの連携ビルドも維持します。

**新規取得した能力**にはランダムな基礎能力1つの小成長を追加。N0.3／R0.5／SR0.8／SSR1.2／UR1.8／LR2.5に、その能力値のランク成長率を掛けます。この取得ボーナスに元成長1.5倍は掛けません。レース報酬・ショップ双方で有効。初期所持・弱点には付きません。重複取得は習熟だけで再成長しません。上限100、小数は蓄積します。

## 接触・復帰・観戦

艇の向きと接触方向から「横の押し合い」「追突」「正面・対向接触」を分け、反発・回頭・傾き・速度損失を変えました。横接触は速度損失を小さくして進路争い、追突は直進方向の衝撃、対向接触は大きな失速と傾きになります。フィジカルによる押し負けの差は残ります。

内側ブイで0.7秒連続してほぼ進めないと、自動でその場の船首を外へ向けます。追加停止や距離加算はありません。通常の「立て直す」は別機能で4秒停止します。転覆・F/Lからは復活できません。

観戦は「自動高速」か「3秒進める」です。自動高速は接戦・発動・ゴール前も減速しません。手動はボタンを押した時だけ、実際のレース時間を3秒進めます。全艇のレース終了が先に来た場合は、3秒未満でも終了します。自動を止めると手動に戻ります。物理計算はどちらも同じ60Hzです。

## 予選・経歴

各シリーズ20人、予選5走、上位6人は優勝戦、7〜12位は順位決定の準優勝戦、13位以下は敗退。必要ポイント欄には現在の6位／12位圏の境界と、それを単独で越えるまでの点数、残り走数を表示します。他選手も加点するため進出保証ではありません。同点でも順位決定方法により入る場合があり、単独超えの点数は安全側の目安です。

選手詳細にはv88以降の出走・勝利、記録内の初勝利、最良ST、水面別成績、優勝・低人気からの逆転を保存します。登録選手にも引き継ぎます。過去版の記録がないレースを新たに作りません。

新人・G3・G2・G1を各2期、最後にSGの全9シリーズ。G1後期終了時の累計賞金1,800万円がSG条件です。登録前ラストショップ、SG優勝戦での登録選手・記憶ライバル招待、登録6人レース、仮想コイン応援も維持します。

## 保存・更新・移行

データ管理に**3つの保存枠**を追加しました。現在の選手・進行中レース・登録選手・ショップなど全データを独立して保存／読み込みできます。保存枠の上書きや読み込み前には、以前の内容を自動退避します。

更新前の生JSONは専用1枠に保存し、通常の上書きバックアップ直近4枠と分けます。通常の保存を繰り返しても更新前専用枠は消えません。次の異なる版への更新時は、新しい更新前データになります。復元はデータ管理から可能ですが、復元後のゲーム計算は現行版です。

localStorageが使えない／容量に達した場合はメモリ退避し、画面に永続保存できない旨を表示します。メモリだけのデータは閉じると失われます。保存枠を端末外へ残すには、その枠を読み込んでJSONを書き出してください。iPhone単体版は共有保存とコピー用JSONに対応します。

旧版の走行位置・時計の基準時刻を維持。進行中のレース前行動の残数も維持し、次のレースから通常2枠へ切り替えます。旧機材は数値を変えず均衡型として扱い、新しい抽選から性格を付与します。能力・機材は整数＋ランク表示、端数保持。賞金は万円未満を表示せず、10,000万円から億を使います。

## 確認方法・今後

レース一時停止のデバッグでST・能力ID・舵負荷・接触・引き波を確認できます。整備デバッグで方向、結果、前後数値、学習係数、追加枠倍率を確認できます。

開発時は `node tests/race-v89-tests.cjs`、`node tests/race-v88-tests.cjs`、`node tests/engine-tests.cjs`、`node tests/android-update-tests.cjs`、`node tests/iphone-tests.cjs`。単体生成後は `python3 tests/static-checks.py` と `python3 tests/iphone-static-checks.py`。旧版テストには廃止仕様の期待値も残るため、全テストの一括成功を現行ゲートにはしません。

次の候補はスタート・旋回の独立練習コース、走行リプレイ、会場別AI、機材別の試走比較です。今回、能力の装備枠制限やNPC難易度の追加変更は行っていません。

## v89のゴール・能力調整

最終周は、スタートと同じ水面ラインを船首が越えた瞬間にゴールとします。船体中心が届くまで待ちません。途中の周回チェックを通過していないショートカットや逆走では完走になりません。ゴールした自艇はそのフレームで停止し、FINISHを表示して残艇の結果を確定します。

同じ能力の同種効果は再発動で更新し、重ね掛けしません。複数の強化が集中した際の能力上昇・速度・加速・操作補助に上限を設けています。彗星航路、水上の軌跡、波を支配する、王者の旋回、SSR以上のVモンキー系を抑えました。SRモンキーターン、低レアの操作能力、防御の妨害無効・反射の性質は維持しています。調整値は `BALANCE_REPORT.md` を参照してください。

v88の途中セーブは、育成・所持金・残行動・走行位置を引き継ぎます。更新前バックアップも残します。
