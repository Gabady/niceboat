# 競艇物語 V121

V120を引き継ぎ、提案の第1段階として保存・能力説明・振り返り・準備画面を改善しました。
基本版、Android Safe版、iPhone Safe版、編集用HTML、素材分離版のすべてに実装しています。
賞金・成長率・レース計算・物語の分岐と報酬条件はV120を維持しています。

## 今回の変更

- **保存の状態を見える化**：端末へ保存できない場合は画面に「一時保存中」と表示し、容量不足と利用不可を区別します。JSON書き出しと保存の再試行ができます。レース中は操作を妨げない短い表示に切り替えます。
- **保存の復旧**：書き込めなかった最新の値をメモリーに保持し、再試行時にまとめて保存します。容量不足で書き込めない場合でも、読み出し可能な既存セーブを読み込みます。一時保存はページを閉じると失われるため、警告中はJSONを残してください。
- **自動保存の処理を削減**：レース中の定期保存では、変更されない登録選手・ライバルのJSONを再利用します。操作による保存時は更新し、走行位置・リプレイ・能力・物語は従来どおり保存します。設定画面で直近の処理時間とデータ量を確認できます。
- **能力の効き方**：「直線能力」と「基礎能力の速度換算」を併記し、加速・フィジカルを仮に5伸ばした場合の変化を示します。1回の練習の成長量や実際の艇速を示す値ではありません。
- **次に試すこと**：前走の早発・転覆・横滑り・接触・引き波などに応じて操作練習への入口を表示し、長期の技の育成も別に提案します。原因や勝利を断定しません。
- **練習から元の画面へ**：結果・準備画面から操作練習へ移動し、再挑戦した後も元の画面へ戻れます。育成の進行・能力・行動回数は変わりません。
- **準備画面の整理**：今回の目標、残りの練習・整備回数、出走前の機会を上部にまとめ、人物・順位・行動ログを折りたたみます。練習と整備を先に操作できます。開閉状態は同じレース中の再表示で保持します。
- **シリーズの区切り**：今節に伸びた能力と次節、保存状態をまとめて示します。

## 起動するファイル

| ファイル | 用途 |
|---|---|
| `index.html` | 基本版。画像・音源・処理をすべて内蔵 |
| `index_android_safe.html` | Android Safe版。基本版と同じ機能・画面・素材 |
| `index_iphone_safe.html` | iPhone Safe版。同じ機能に画面高追従・JSON共有保存の補助を追加 |
| `index_editable.html` ＋ `src/` | 編集用。JSを外部ファイルから読み込むためフォルダごと利用 |
| `web/index.html` ＋ `web/` 内のファイル | 素材分離版。フォルダごとWeb配信して利用 |

HTMLを実行できるブラウザーで開いてください。iPhoneではSafariで配信したURLからの利用を想定します。この配布物に公開URLは付いていません。

## 既存セーブ

セーブキーは `kyotei_monogatari_v80` のままです。V120の能力・機材・賞金・行動残数・レース中断位置を引き継ぎます。V116/V117の互換も確認しています。
更新前には設定画面からJSONを書き出してください。ファイル名や置き場所、ブラウザーを変えると、保存領域が分かれる場合があります。その場合は新しい版の設定画面からJSONを読み込んでください。

## 今後の変更手順

ユーザー指定により、今後の実装はすべてのHTMLへ同時に反映します。詳しい作業規則は `AGENTS.md` に残しました。

1. `src/` のゲーム処理、基本 `index.html` のHTML・CSSを変更します。
2. `python3 tools/build_all.py` を実行します。基本・両Safe・編集用・素材分離版を再生成し、内容一致も検証します。
3. 関連する検証を実行し、両Safe版を含めて配布します。

`tools/verify_all.py` は全スクリプトとHTML/CSS、画像・音源のハッシュまで比較します。端末固有の補助とファイル参照形式、意味のないスクリプト前後の改行だけを正規化します。

## V121の確認範囲

- 5種類のHTMLで全ゲーム処理・画面・CSS・素材の一致。
- 基本版・Android Safe版・iPhone Safe版の内蔵コードを直接実行し、4シナリオずつ新規育成・練習・整備・結果・セーブ復元を検証。
- 既存29項目とV120修正10項目の回帰確認。
- 保存失敗・復旧・V120移行・能力診断・保存データ保持の10項目。
- 画面生成と操作処理の9項目。4シナリオの準備、操作練習からの復帰とデータ不変、シリーズ結果、保存警告と再試行をDOM代替環境で確認。

結果は `tests/parity-v121.json`、`tests/safe-sync-v121.json`、`tests/coaching-v121.json`、`tests/ui-logic-v121.json`、`tests/verification-v121-base.json` に記録しています。

**ブラウザーでの描画・タッチ・音出し、Android/iPhone実機の確認は今回未実施です。** ブラウザー本体の取得に失敗し、確認用クラウドブラウザーからローカル版への接続も制限されました。DOM代替環境の確認は実ブラウザー確認ではありません。`tests/` 内のV120ブラウザー記録は旧版のものです。

V120までの詳しい仕様・調整理由は `README_V120.md`、以前の変更履歴は `CHANGES_AT.md` を参照してください。
