# 競艇物語 v86 — 育成 × 一人称ボートレース

選手を育て、自分で操舵・アクセル操作をして6艇の水面を走る、スマホ縦画面向けのゲームです。v70.1の育成と全9シリーズを引き継ぎ、プレイヤーが出走するレースを一人称の操作型へ変更しました。

## iPhone版

`index_iphone_safe.html` を追加しました。Safariの表示領域・安全領域と共有保存へ対応しています。開き方は `IPHONE_README.md` を参照してください。ファイルのプレビューだけではJavaScriptを実行できない環境があります。iPhone実機での動作は未検証です。

## 起動

Androidでは `index_android_safe.html` をダウンロードし、JavaScriptが動作するブラウザで開いてください。3D描画を初期化できない場合は、軽量な一人称表示へ自動で切り替えます。この1ファイルにすべてのCSS・JavaScriptを埋め込んでいます。通信、外部ライブラリ、画像のダウンロードは不要です。APKではありません。

PCまたは通常のWeb公開では、ZIPを解凍して同じフォルダの `index.html` を開きます。ソース編集時は、分割ファイルを編集して `python tools/package.py` を実行すると単体版とZIPを再生成できます。プレイにはPythonもNode.jsも不要です。

Androidのファイルアプリ内プレビューがJavaScriptを許可していない場合は、ブラウザで開き直してください。軽量表示にも失敗した場合は「観戦モードに切り替える」で育成を進められます。Android実機でのタッチ操作・描画速度は未検証です。

## 操作方法

1. 「選手をつくる」で名前・初期能力と、イージー／ノーマルを決定します。再抽選しても入力名と選んだ難易度を保持します。
2. シリーズへ参加し、各レース前に練習または機材調整を選びます。
3. 出走表で機材と天候を確認し、標準・出力重視・安定重視から設定します。
4. 出走前に「自分で操船する」または「観戦モードで進める」を選びます。手動の場合は「水面へ出る」で10秒の助走が始まります。カウント中も走行できます。4〜6コースは後方からのダッシュ配置です。
5. レース画面の左側・下半分に指を置き、左右へドラッグして操舵。スライダーの見た目・大きさはv84と同じです。ノブ自体をつかむ必要はありません。指を置いた時の舵角から相対的に動かせます。細い縦線は指の指定位置、丸いノブは実際の舵角です。光る帯が現在動かせる範囲です。右の「加速」を押している間は加速し、旋回中も速度を維持します。離すと水の抵抗で減速します。ブレーキはありません。両手を同時に使えます。
6. 赤い内側ブイを回り、1周600mのコースを反時計回りに3周するとゴールです。最初のターンは右側の1マーク、次が左側の2マークです。
7. ゴール後の「リザルトへ」で賞金・成長・走行の要点を確認し、次のレースへ進みます。

ターン前は加速を離して減速し、左へ舵を切ります。曲がり終えたら舵を戻して加速。全開の急旋回でも自動で速度を落とさず、横滑りと傾きが増えます。フィジカルが低いまま長く無理をしたり、高速旋回中に強く接触すると転覆する危険があります。衝突・ブイ接触による失速は残り、その後は通常の加速で回復します。旋回・フィジカル・プロペラ・ボート安定性や防御系スキルが扱いやすさに影響します。

水圧が高いほど舵の可動域と動く速度が小さくなります。全開でのターンや横滑り中は特に重くなり、指を端へ動かしても丸い舵は遅れて動きます。反対側へ切り返す場合も時間が掛かります。旋回能力はこの負荷を軽減し、フィジカルは主に波と傾きに作用します。左右の端まで即座に切る操作はできません。

水面の淡い線は進行方向のガイドです。ガイド、視点の揺れ・雨風の動き、軽量表示は一時停止メニューから切り替えられます。軽量表示でも同じコースを同じ操船ルールで走ります。

| 操作 | スマホ | PC |
|---|---|---|
| 左右操舵 | 画面左側の下半分から左右へドラッグ | ← → / A D |
| 加速 | 加速ボタンを長押し | ↑ / W |
| 減速 | 加速ボタンから指を離す | ↑ / W を離す |
| 一時停止 | 右上のⅡ | Esc |
| 立て直し | 一時停止メニュー | 一時停止メニュー |

ブイの判定余白を1.3mから0.45mへ減らし、擦り続けた時の連続した大幅減速を抑えました。ブイ接触後に低速になるか、境界に擦り続けていると「ブイから離脱」が表示されます。押すと同じ進行地点の空いたレーンへ移動し、0.7秒停止して再発進できます。再使用は6秒後からで、移動先が混雑している場合は使えません。NPCと観戦中の自艇は約1.2秒スタックすると自動で同じ復帰を行います。

通常の「立て直す」も残り、現在の進行地点で姿勢を戻し、4秒停止して再発進します。周回は増えません。転覆後やF/L判定後の復活はできません。助走中も立て直しは使えません。スタート後の制限時間270秒の未完走・任意リタイアは棄権扱いで、賞金・予選ポイントは0です。

タブ切替、画面を離れる操作、ウィンドウのフォーカス喪失で停止します。復帰時は「操船を再開」を押してください。

## v86の難易度

イージーは勝ちやすさと控えめな成長、ノーマルは高い成長・高レア獲得と強い対戦相手を組み合わせます。G3以降は両方ともNPCの走行性能を段階的に強めます。イージーのNPCもプレイヤーに合わせて能力とレア度の伸びを抑え、低成長だけが不利にならないようにしました。

| グレード | イージーNPCの走行係数 | ノーマルNPCの走行係数 | ノーマルNPCの追加基礎値 |
|---|---:|---:|---:|
| 新人 | 1.000 | 1.000 | 0 |
| G3 | 1.008 | 1.008 | +0.5 |
| G2 | 1.015 | 1.018 | +1 |
| G1 | 1.021 | 1.028 | +1.5 |
| SG | 1.026 | 1.038 | +2 |

走行係数は既存の難易度別NPC性能へ重ね、最高速・ターン目標速度に係数、加速に係数の2乗を掛けます。手動自艇にはこのNPC補正を掛けません。NPCも同じ水面、操舵負荷、衝突と転覆の判定を受けます。タイムを後から書き換える処理ではありません。

イージーNPCは新人を基準にしたグレード別の能力増加を82%にし、能力抽選のレア度も1段階下げます。最高レアはURです。ノーマルのSG NPCは通常枠SR〜UR、19人中4人の特別枠にLRを持たせます。通常枠でLRが何枚も重なる抽選を抑えます。これにより、イージー側の低成長と低レア報酬だけが後半の不利につながる状態を抑えます。

| 項目 | イージー | ノーマル |
|---|---|---|
| NPCの走り | 判断に余裕あり。G3以降に小幅強化 | 判断が速い。G3以降の能力・走りを強化 |
| 練習・レース後の基礎成長 | 従来の75% | 従来の100% |
| 調整能力の成長 | 従来の75% | 従来の100% |
| 勝利・優勝報酬のレア度 | 通常の抽選から1段階下げる。Nが下限 | 従来どおり |
| SG優勝報酬 | UR確定 | LR確定 |
| 招待選手に先着した報酬 | 相手の対象能力を1段階下げたレア度で獲得。同カテゴリを優先 | 相手の対象能力をそのまま獲得 |
| 通常／ラストショップ | SSRまで | 従来どおり、最高UR |
| 賞金・機材調整幅・次走補正 | 共通 | 共通 |

ノーマルの着順別レース成長の基準値は1〜6着で0.78/0.74/0.70/0.66/0.62/0.58。1着の値は維持し、2着以下の成長を少し増やしました。イージーは0.78/0.71/0.63/0.56/0.50/0.45の従来値に75%を適用します。勝てない時でもノーマルの育成を続ける意味を残します。

成長75%は非SGの成長倍率、成長型、育成能力、連続調整減衰などに重ねて適用し、小数を内部に蓄積します。ショップ価格、行動数、能力発動率、勝利時の獲得抽選率、弱点の獲得／克服、SG進出賞金条件は共通です。初期の「好スタート」も共通です。観戦へ切り替えても選手の育成倍率・報酬条件は維持します。

v81の選手は、育成報酬を下げないノーマルとして引き継ぎます。v81の走行中セーブは座標・時間・周回をそのまま再開し、再開後の挙動にはv85の調整を適用します。

## v85の能力バランスと連携ビルド

5能力は手動・観戦・NPCで共通の走行計算に使います。直線と旋回の強みを残しながら、スタートを再加速の応答にも、フィジカルを加速・グリップ・終盤の消耗にも反映しました。v85の連携追加では成長倍率・賞金・能力獲得抽選を維持しました。v86の着順別成長の変更は上記の難易度説明を参照してください。

| 基礎能力 | 主な役割 |
|---|---|
| 直線 | 最高速、直線の追走力 |
| 旋回 | 舵の負荷軽減、横滑りの収束、ターンのグリップ |
| スタート | 助走とST精度、アクセル応答、立ち上がり加速の一部 |
| 加速 | 再加速の出力、エンジン応答 |
| フィジカル | 波・接触・転覆への耐性、グリップ、加速補助、スタミナ維持 |

以下の連携は、指定された2系統から各1能力を持ち、基礎能力の条件を満たすと使えます。一時強化では基礎条件を代用できません。発動中だけ効果と代償が加わり、同じ連携を重複所持しても重なりません。手動・観戦・NPCで共通です。

| 連携 | 組み合わせの例／必要基礎能力 | 有効な場面と効果 | 代償 |
|---|---|---|---|
| 先手必勝 | 好スタート系＋内コース／進入系、スタート40以上 | 内1〜2コースの最初の200mで応答・グリップを強化 | 消耗が少し増える |
| 差し返し | 差し／モンキー系＋グリップ／外攻め系、加速40以上 | ターン出口から4秒間、再加速と応答を強化 | 発動中の伸びが少し下がる |
| 荒水の構え | 雨・荒天・波系＋体幹・安定系、フィジカル40以上 | 雨または風速6以上で引き波・波の影響と消耗を軽減 | 発動中の伸びが少し下がる |
| 攻防一体 | 妨害系＋無効／反射系、スタート・フィジカル35以上 | 他艇が18m以内にいる間、応答と接触耐性を強化 | 発動中の伸びが少し下がる |
| 整備の継走 | 洞口スペシャル系＋整備系、加速40以上 | 2周目の応答を補い、消耗を軽減 | 発動中の伸びが少し下がる |

図鑑の「連携」を開くと、対象能力の正式名称を含む完全な組み合わせと条件を確認できます。ホームに成立中の連携と不足条件、ショップに連携を狙うおすすめ理由を表示します。走行中は有効な連携名を表示し、初めて使った時に実況、結果にも使用した連携を残します。洞口スペシャルの3周目の反動は消えません。

UIはミント・水色・金色のアクセントと文字のコントラストを少し強めました。操舵の判定は左下半分へ拡張していますが、丸いノブと可動域の表示、重い実舵の制限は維持しています。加速・一時停止・離脱などのボタンは操舵より優先して反応します。

## 追加行動の通知と雨風の演出

「朝練の習慣」「整備の余白」が発動したら、レース前画面の上部に能力名、練習／調整＋1回、専用行動の残数を表示します。初回表示時は通知も出ます。通知済みの状態を保存するため、画面を開き直しても毎回通知は繰り返しません。追加調整はモーター・プロペラのどちらにも使えます。

| 条件 | 画面の演出 |
|---|---|
| 55km/h以上 | 画面の左右へ流れる速度風 |
| 風速6m/s以上 | 端を横切る風の筋。強風ほど本数・長さが増加 |
| 天候が雨 | 雨筋。雨の演出強度は0.65＋風速×0.025、閾値0.6以上で表示 |

雨は現在の天候データに強弱区分がないため、雨天を基準に風速で演出量を調整します。雨筋の向きには風向も反映します。演出は視認性を保つため半透明にし、順位・操作ボタン・カットインより後ろに重ねます。ゲーム側の乱数・能力発動・着順へ影響しません。

WebGLと軽量表示で共通のCanvas 2D演出を使い、最大70本、約30fps、描画倍率1.5倍以下に制限します。演出用Canvasを利用できなくても操船は続きます。一時停止中は消し、「視点の揺れ・雨風の動き」をオフにすると少数の静止表現に切り替えます。端末の「動きを減らす」設定も初期値へ反映します。

## 能力と機材の表示

小数は内部で保持し、画面の値は切り下げ整数＋S〜Eランクで表示します。たとえば49.8に0.4成長すると内部値50.2、表示は50 Cとなり、その回の表示成長は＋1です。表示上＋0でも端数は失われません。

| 0〜100の値 | ランク |
|---|---|
| 90〜100 | S |
| 80〜89 | A |
| 65〜79 | B |
| 50〜64 | C |
| 35〜49 | D |
| 0〜34 | E |

基本能力、調整成功・ムラの能力値、コンディション、安定性はこの基準です。調整ムラは高いほど振れ幅が大きく、ランクが高いこととリスクが低いことは同じではありません。

機材の「＋直線」などは負の値もあるため、各性能範囲を0〜100に換算してから同じランク基準を適用します。モーター直線・プロペラ旋回は−15〜30、両方の加速は−15〜25、ボート旋回は−2〜9、ボート加速は−2〜8です。数値自体は元の補正値を表示します。

賞金は万円単位の整数表示で、10,000万円以上では億も使います。所持賞金・累計賞金・獲得賞金・価格・SG条件の表示を統一しました。万円未満の表示だけを切り捨て、計算用データは保持します。目安倍率、タイム、確率は必要な精度で表示します。

| 内部金額（万円） | 表示 |
|---:|---|
| 9999.9 | 9,999万円 |
| 10000 | 1億円 |
| 12345.6 | 1億2,345万円 |
| 100000 | 10億円 |

## 引き継いだ育成仕様

- 新人前後期→G3前後期→G2前後期→G1前後期→SGの9シリーズ。
- 各シリーズ20名、プレイヤー出走の予選5レース。各NPCも裏のレースを含めて予選5走。
- 予選1〜6位は優勝戦、7〜12位は準優勝戦、13〜20位は敗退。準優勝戦もそのシリーズの最終戦です。
- 練習は基礎成長と次走能力補正。同じ対象の連続調整は調整能力成長が100%→55%→22%に減衰。練習でリセット。
- シリーズごとの機材抽選。調整した機材は同シリーズ中に維持。
- 特殊能力N〜LR、妨害・無効・一部/完全反射、弱点と克服。反射の再反射はなし。
- 実走中の通常強化は原則8秒、妨害・反射は4秒。下記2系統には専用の周回・時間条件があります。スタート強化は助走から発走後まで、スタート牽制は有効スタート時間の終了まで継続。最高速だけでなく引き波・接触・横滑り・エンジン応答にも作用。
- 走行ゾーンへの進入時に発動抽選。ターン系・直線系は各周にチャンスがあります。育成・整備・人気系は対応する場面で作用します。
- G1後期終了時に累計賞金1,800万円でSG進出。買い物で所持金が減っても累計賞金は減りません。
- 通常能力ショップはG3前期以降、毎シリーズ更新・購入数制限付き。ノーマルのURはG1以降、イージーはSSRまで。LRと弱点は通常販売なし。
- SG優勝でノーマルはLR、イージーはUR獲得。登録選手・記憶ライバルの特別参戦はSG優勝戦のみ。先着報酬にも上記の難易度を適用。
- 育成終了時は5候補から1つだけのラストショップを経て登録できます。
- 登録選手6人を選ぶおまけレースにも操船を適用。操作する1人を選択でき、育成原本は変化しません。仮想コインは任意、現金との交換や購入はありません。

実走の着順は走行距離と実際のゴール時刻で決めます。NPCにも同じ水面物理と接触を適用します。プレイヤーが出ていない裏の予選・別組の最終戦では、従来のフェーズ計算を使用します。

## 助走スタートとスタート能力

船首がスタートラインを横切る時刻を、60Hzの更新間でも補間して判定します。

| 通過時刻 | 判定 |
|---|---|
| 0秒より前 | F（フライング） |
| 0秒以上、1秒未満 | 有効スタート。STを記録 |
| 1秒以上、または1秒以内に未通過 | L（出遅れ） |

F/Lはそのレースの賞金・予選ポイントが0となり、次のレースには進めます。育成全体を終了させる罰則は設けていません。観戦へ切り替えてもF/Lを取り消せません。

スタート能力は助走中のエンジン応答、加速の立ち上がり、画面に出す発進目安の読み幅に反映します。NPCの目標STと調整精度にも作用します。能力が高くても早く踏めばFです。現在の速度・機材・発動能力から「今から全開で走る場合」の到達を予測し、全開の目安を表示します。目安の時刻に合わせた自動発進や、F回避の強制停止は行いません。

## 水面・接触・駆け引き

| 要素 | 実走での変化 |
|---|---|
| 直線 | 最高速。低能力では伸び足そのものが不足 |
| 加速 | 再加速と通常走行のアクセル応答 |
| 旋回 | 水圧による舵角制限と舵の遅れの軽減、旋回力、横流れを収める力 |
| フィジカル | 横波・引き波への耐性、消耗、接触で押されにくさ |
| 引き波 | 各艇の航跡が5秒間残り、後続の横流れ・グリップ・傾きを変える。全開時の旋回減速は補うが、蛇行・接触・回避によるタイム損失は残る |
| 接触 | 船首・中央・船尾の当たり判定。双方の速度、位置、向きに反作用 |
| コース境界 | 外へ寄せた小回り防止ブイ列の内側に入れない。境界への押し戻しで距離を稼げない |
| NPC | 周囲の空きと能力に応じて先マイ、差し、まくり、まくり差し、内を守る、引き波回避を選ぶ |

v82はフィジカルによる引き波耐性を少し強めました。防御能力がなくても低能力時から小さく軽減し、高フィジカルほど軽くなります。波そのものは消さず、追走ラインの乱れと避けるための距離損を残して先行の有利さを維持します。

低能力のNPCも横滑りや接触を起こします。NPCの操舵・アクセルはプレイヤーと同じ計算に入力され、コースへ吸着させたり速度を直接設定したりしません。

能力図鑑・ショップの「実走」欄に、物理モードでの条件と効果を追加しました。「波を支配する」は引き波を吸収、「不動のターン」は接触で船首を振られにくくし、「全速まくり」は外での伸びと大きい引き波の代わりにグリップを少し下げます。「強襲ダンプ」は9m以内にだけ届き、攻撃側にも反動があります。無効化・反射は水面の追加効果にも適用し、反射の再反射はありません。これらの妨害技はゲーム独自の要素です。

## 操船せず、観戦で育成を進める

出走前、操船途中、登録選手レースのいずれも、**600m×3周の物理レースを観戦する方式**へ統一しました。出走前からの観戦には10秒の助走もあります。楕円の周回インジケータ、中央順位、実況、高レアカットインを表示します。「3秒進める」または「自動進行」で進めてください。

途中切替では現在の位置・速度・周回・水面・F/L・転覆・能力発動を引き継ぎます。AIが同じ艇の操舵とアクセルを担当し、自艇には難易度別の基礎NPC走行補正と下記の観戦操船係数を適用します。グレード上昇によるNPC追加補正は受けません。勝敗の固定や獲得賞金の上乗せは行わず、ゴールは3周です。旧5フェーズの指示選択はこの観戦画面から取り除きました。出走前の標準・出力重視・安定重視は使えます。

賞金・成長・能力獲得は、選手に保存した難易度の通常ルールを適用します。中断後は観戦画面から再開し、自動進行は停止状態になります。

## v86の観戦バランス

観戦自艇の補助をイージーは最高速−0.5%・加速＋0.5%・ターン目標±0%、ノーマルは最高速−1.5%・加速＋0.5%・ターン目標±0%に下げました。v85では両方とも3.5%・6%・1.5%でした。

観戦中だけ、全艇の各基礎能力を出走6艇の平均へ18%近づけます。ただし補正は各能力±4.5以内。能力の大小を逆転させず、元の成長値や所持スキルも変更しません。5能力すべての重み、機材・天候・作戦・連携の差は残ります。

さらに、全艇にレース中なめらかに変わる調子を加え、最高速±1.2%、加速±2%以内で揺らぎます。保存済みの艇ごとの値と進行距離から計算するため、停止・読み込みで再抽選されません。先頭だけを減速させたり、最後尾だけを強制的に追いつかせたりしません。F/L・転覆や大きな能力差による大差は起こり得ます。

旧セーブも読み込めます。進行中のレースは位置や失格を保持して新しい走行係数を適用します。NPCの追加基礎値・レア度変更は次にシリーズを生成する時から適用されます。通常育成でSGを争える難度を目標としますが、実機での人の操作技量や育成方法による勝率は未測定です。

## 洞口スペシャル／モンキーターン（2系統8能力）

漫画を題材にしたご指定を、ゲームの水面物理に作用する独自パラメータで実装しました。各系統にSR・SSR・UR・LRがあり、同系統を複数持っている場合は最上位だけ有効です。系統間は併用できます。習熟を重ねてもこの2系統の固定効果は増えません。通常の獲得抽選・ショップ候補に加え、LRは従来のSG等の特別報酬枠です。イージーの報酬レア度低下・ショップ上限は維持します。

### 洞口スペシャル（整備）

有効スタート後に1周目の強化が始まり、2周目で通常性能に戻り、3周目に反動が発生します。スタート能力とF/L判定は強化対象外です。反動はこの能力に付随する性能変化なので、弱点克服や妨害反射では消せません。

| レア度・名称 | 1周目：直線／加速／旋回 | 3周目：直線／加速／フィジカル |
|---|---|---|
| SR・入門 | ＋2／＋2／＋1 | −1／−1／−1 |
| SSR・熟練 | ＋12／＋14／＋7 | −7／−8／−5 |
| UR・極 | ＋24／＋26／＋12 | −13／−14／−8 |
| LR・到達点 | ＋38／＋40／＋18 | −20／−22／−12 |

値は走行時の能力補正です。複数能力の正の補正合計が36を超える部分は40%に減衰する共通ルールがあるため、最終的な速度増分そのものではありません。SRは非常に小さな差です。逆走して周回境界を往復しても強化をやり直せません。

### モンキーターン（戦術）

1マーク・2マークで、アクセル全開、実際の舵が左25%以上、速度6m/s以上になった時に抽選します。各マーク1回、3周で最大6回の抽選です。外した後の押し直しや読み込みで再抽選しません。

| レア度・名称 | 発動率 | 継続 | 旋回の効果 |
|---|---:|---:|---|
| SR・モンキーターン | 45% | 0.75秒 | ごくわずかな補助。水をつかむ力は約1.14倍、最大旋回力は約1.03倍 |
| SSR・Vモンキー | 58% | 1.15秒 | 舵の負荷を軽減し、短時間の全速旋回を助ける |
| UR・超絶Vモンキー | 70% | 1.35秒 | 横滑りを強く抑え、全開のまま鋭く向きを変える |
| LR・究極Vモンキー | 82% | 1.45秒 | 水をつかむ力を大きく高め、V字に近い鋭い旋回を可能にする |

船首の旋回、横滑りの収束、舵の負荷軽減へ作用します。アクセルを緩める・実舵が左20%未満になる・直線へ抜けると、その間は効果が止まります。持続時間内に条件を満たし直すと残り時間だけ有効です。境界や他艇を通り抜けたり、位置を瞬間移動したりする処理はありません。鋭さは能力・水面・入力にも左右され、どの状況でも完全なV字になる能力ではありません。

発動時はミニマップ上に能力名・レア度と「1周目・出力上昇」「3周目・反動」「全速旋回」を表示し、リザルトにも要点を残します。

## Androidの描画と操作

v80で一部端末に表示された「3D描画プログラムを準備できませんでした。」に対応し、頂点・フラグメントシェーダー間の共有変数の精度指定を合わせました。ただし端末側の詳細エラーログは取得していないため、その画像だけから実機での失敗原因を一つに断定してはいません。

WebGLを利用できない・シェーダーのコンパイルやリンクに失敗する場合も、新しいCanvasに切り替えて軽量な一人称表示を開始します。WebGL用のCanvasをそのままCanvas 2Dへ転用しない構造です。視点・コース・操船計算・着順は共通です。

Pointer Captureに失敗した場合でも指を離すと入力を解除し、Pointer Eventsがない環境にはTouch Eventsの代替処理を用意しました。左の操舵と右の加速を2本指で入力できます。

育成セーブの保存キーはv80と共通です。走行状態は新コース用に更新しています。旧ファイルから新しいファイルへ移すと保存領域が変わることがあるので、必要なら旧版の「データ管理」からJSONを書き出して引き継いでください。

## セーブと旧版からの移行

localStorageに育成、登録選手、ライバル、ショップ、行動バランス、走行中の位置・速度・抽選状態を保存します。走行中は約2秒ごと、一時停止や結果確定時にも保存します。復帰時は停止状態から再開します。

同じ保存領域にv70.1のセーブがあれば自動移行します。ファイルの場所・名前・ブラウザが変わって保存領域が変わった場合は、旧版の「データ管理」でJSONを書き出し、新版で読み込んでください。

v81 / v82の実走中・3周観戦中データはそのまま継続し、新しい操舵・NPC調整を適用します。旧1周観戦の未完了データは進行割合を1周目の位置へ換算し、3周ゴールへ延長します。旧観戦には実測の速度・タイムがないため、速度0、移行用ST0.30秒と補完した経過時間から再開します。すでに転覆した艇と確定済みの育成は保持します。

v80 / v80.1の未完了レースは、旧コースの距離を新コースへそのまま流用できないため、助走開始へ戻します。v70.1の未完了レースも出走前へ戻します。確定済みの賞金・能力・シリーズ進行、機材、使用済み行動は維持します。すでに確定した旧レースの結果は従来表示を残します。v31等は移行対象外です。

localStorageが拒否された場合はメモリへの一時保存に切り替わります。画面に「一時保存中」と出たら、終了前にJSONを書き出してください。コピー用テキストからの保存も可能です。

## デバッグ確認方法

レース右上のⅡ→「実況・操船デバッグ」を開きます。走行距離、速度、舵の指定位置・実舵・可動域・負荷・動く速さ、新能力の周回と抽選済みマーク、滑り、傾き、転覆危険度、難易度、演出の閾値と現在強度、チェックポイント、ST・F/L、NPCの選択進路、引き波の影響と軽減率、接触回数、発動ID、妨害・反射、カットイン対象、現在有効な連携を確認できます。観戦モードは画面下の「レースデバッグ」にあります。「カットイン確認」はLR鏡面水域の見た目だけを表示し、能力・賞金・勝敗を変えません。

通常画面の順位・タイム・ログに計算スコアは出しません。調整の前後値と成長減衰はレース前アクションの「調整デバッグ」に表示します。能力・機材の前後値はここでも整数＋ランクです。

開発者向け計算検証は以下です。ブラウザやAndroid実機を自動操作するテストではありません。

```sh
node tests/engine-tests.cjs --json
node tests/android-update-tests.cjs
node tests/race-v83-tests.cjs
node tests/race-v86-tests.cjs
node tests/iphone-tests.cjs
python tools/package.py
python tests/static-checks.py
python tests/iphone-static-checks.py
```

v85は上記の変更点と直結する検証を再実行しました。旧版のベンチマーク・結果は比較履歴として残しています。次回は `DEVELOPMENT_HANDOFF.md` を最初に読み、差分と関係するテストだけを確認すると効率的に再開できます。

## 拡張案
