# 競艇物語 V117

物語の改稿、G1レーサーの再起編、スタート仕様の更新版です。

## 遊び始める

- Android・PC：`index.html`。単体HTMLに画像・音楽・プログラムを内蔵しています。
- iPhone：`index_iphone_safe.html`。Safariでは配信したページのURLから開いてください。ファイルアプリのプレビューでは動作しない場合があります。
- 更新前に、旧版の「設定・セーブ」でセーブJSONを書き出してください。必要なら新しい版で読み込みます。
- 新しい物語は「選手をつくる」→「メインシナリオ」→「折れた航跡 — G1レーサー挫折編」で開始できます。「おまかせ」は全4ルートから抽選します。

## 今回の変更

### 物語

本編「灯を継ぐ」「冷たい勝算」「沈まない旗」の全30場面に、人物の行動・具体的な品物・以前の出来事への言及を加えました。各ルートで扱う家族、競争、応援の葛藤を区別し、勝利・上位進出・敗退に応じた返答を追加しています。

ヒロイン6人、師匠5人、主ライバル5人の各ルートでは、序盤と終盤に、その人物の変化が伝わる場面を追加しました。既存の選択の効果・好感度条件・報酬条件を維持しています。

新本編「折れた航跡」は序章＋9章。事故による負傷で離脱したG1経験者が、復帰許可を得た後、今の身体に合う走りを育て直します。ゲーム内では復帰シリーズ前期・後期（新人シリーズと同じ競技条件）からG3、G2、G1、SGへ進みます。G1から直接始めるモードではありません。

花守凪、朝凪瑞希、赤嶺との会話は、再起編だけで専用の内容に切り替わります。凪はローイング競技を離れた人、瑞希は自身の状態を確認して休養・復帰する現役選手、赤嶺は肩を壊した経験を持つ師匠として、経験の違いを描いています。凪・瑞希は各7話と最終戦前の会話、赤嶺は全5話に対応します。

再起編の「今節の約束」は、有効完走3回でフィジカルを補強する道と、3着以内2回で加速を強化する道です。完了済みの約束は重ねて精算しません。

### スタート

| 対象 | 早発許容 | 操作・表示 |
|---|---:|---|
| 通常選手 | 基礎スタート能力 × 0.002秒、最大0.20秒 | 50なら0.10秒、100なら0.20秒 |
| 神楽瞬、挺王、最終決戦のライバル | 0.30秒 | 毎走、0.30秒前のライン通過を狙う専用のアクセル制御 |

全艇、最初に船首がスタートラインを越えるまでは直進固定です。左右操作、横風、引き波による横方向の移動を助走中は止め、助走中の艇への接触も処理しません。アクセルと姿勢操作は利用できます。通過した次の物理更新から通常の操舵になります。

早発は内部の実通過時刻と許容幅で判定します。許容を超えればFです。基礎能力は0〜100に収めて計算し、一時的な技能・機材補正は許容幅に加えません。特例はNPCの役割に限定します。最終決戦以外のライバルや通常の高能力選手には0.30秒の特例を与えません。

有効な早発と時刻ぴったりのスタートは **ST 00:00**。0.12秒後は **ST 00:12**、1.49秒後は **ST 01:49**です。区切りは「秒:百分の一秒」で、分:秒ではありません。出遅れLの境界は1.50秒です。

### セーブ

既存の選手・ルート・能力・好感度・選択結果を保持し、新シナリオへ強制変更しません。V116の整備データを古い移行へ通さないようにしました。進行中レースの保存位置は読込時に保持しますが、未通過の艇は再開時から今回の直進・早発ルールを適用します。確定済みのF/Lは変更しません。

改稿した会話は新しい読書位置で冒頭から確認できます。記録の再読では成長・報酬を付与しません。V117で生成する本編の本文は場面発生時に保存し、その後の結果と混ざらないようにしています。

## 編集する場合

ゲーム本体は単体HTMLだけで動きます。編集用に展開する場合は、ZIPを解凍したフォルダで `python tools/extract_source.py` を実行します。`src/` に30本のJavaScript、`index_editable.html` に編集用の入口が作られます。変更後は `python tools/rebuild.py` で単体HTMLへ反映します。

元の画像・音源、V116の艇体・レーサー描画を内蔵して引き継いでいます。Webへの公開操作はこの配布物には含みません。
