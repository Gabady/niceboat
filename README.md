# 競艇物語 V134

改善提案の後半5項目（6〜10）を実装した版です。前半5項目のV133も含みます。金銭が必要な好感度イベントの廃止、ヒロイン全7人×10話、ライバル全5人×8話、第8話で交際・第10話は最優秀シリーズ優勝戦出場時に解放、モーター／プロペラ整備と条件付きティルトを維持しています。

## 後半5項目の実装

6. **その日の練習機会**：雨・強風の水面、前のライバル対戦での敗戦、入門済み師匠による確認走の3種類。天候や前の記録から出走前に決まり、再読込で抽選し直しません。通常の練習を選ぶこともでき、使わなかった機会は次走へ持ち越しません。
7. **ライバルと実レースの連動**：同走したレースの双方の着順、失格、練習した能力、走行中の実践、操作方式を保存。結果画面、次に同走する時の準備画面、新しく始まるライバル対話に反映します。5人それぞれの反応を用意し、同じ課題を残した再戦も覚えます。相手の能力や操船AIを後から強くする補正は加えていません。
8. **人物同士の日常**：澪とライバルの取材、紬となつの案内図、灯と父の工具、凪の忘れ物、奏の録音、瑞希との予定調整、師匠とライバルの片づけ、ライバルとの昼食の8種類を追加。必要な人物と出会っている時だけ、一節につき最大1件発生します。第8話で友人を選んだ相手には、7人それぞれに対応する友人としての近況場面も用意しました。関係を変えずに会話を続けます。
9. **表示と進行の整理**：結果画面は「まず一つ、確かめること」を先に表示。根拠・できたこと・区間の記録は折りたたみ、次走ボタンを詳細な成績より手前へ移動しました。ライバル交流は、選択前の本文で練習枠の消費を説明し、選択肢は返答文だけに統一。好感度が上がる選択を予告しません。
10. **周回とエンディングの振り返り**：「持ち帰ったもの」で、最後の本編の課題、実際のレースの約束、よく選んだ練習、最後のライバル対戦、出会った相手との関係、読んだ日常を振り返ります。終了時の本編・日常を読んだあとに自動発生。途中登録を含めて登録選手にも保存します。「選んだ道の記録」から既読の返答・日常・振り返りを再読でき、未読の人物や選ばなかった返答は一覧に出しません。

## 練習機会と記録の扱い

- 既存の練習1回を使います。賞金・好感度は変えず、新たな体力や通貨は追加しません。
- 通常自主練の基礎量を1.1倍にして対象能力を練習し、技のコツを0.4加算します。半量の追加枠では両方とも半量。能力とコツの上限は既存どおりです。1つの機会は1回限りです。
- 天候機会は予選の偶数走と最終戦の前に、雨なら旋回・強風ならフィジカルを確認。師匠の確認は入門後の第4走前に優先します。敗戦の確認は前の同走で相手に有効先着を許した時、予選の奇数走前に用意されます。
- 実践は既存の技の実測条件で判定します。有効完走での達成／未達、失格等による対象外、旧形式などで記録不足を区別します。観戦・自動走行の結果を、ユーザーの操作の評価とは書きません。
- 特別練習そのものでは好感度を授与しません。従来の通常特訓などの処理は継続します。
- 日常会話も同じ節目の会話数制限に従います。レース結果を先に見せ、持ち越した場面は保存します。最優秀優勝戦前の第9→10話は優先します。

## セーブと負荷

保存キーは `kyotei_monogatari_v80` のままです。能力・賞金・交際・既得報酬・登録選手・進行中レースを維持します。V133以前のセーブに、存在しない過去の対戦記憶や日常を作り足しません。新しい対戦記憶は更新後にレースを終えた時から残し、既に保存された対話の本文は更新後も固定します。

追加処理は準備・練習・結果確定・会話の節目で動作します。毎フレームの計算、新規画像・音声、定期的な監視処理は追加していません。保存する機会・対戦は各60件以内、日常は8件以内です。実機の速度改善やFPSは未計測です。

`python3 tools/build_all.py` で全HTMLを生成し、`python3 tools/verify_all.py` で処理・CSS・素材の一致を確認します。梱包は `python3 tools/package_v134.py`。V134の検証結果だけを `tests/*-v134.json` に記録します。

## 本編ごとの実践

|物語|方針A|方針B|
|---|---|---|
|父の工房|別々の二走で同じ部位を整備。実践中は成功した整備の仕上がりを少し補助。|モーターとプロペラを一度ずつ整備。実践中は整備経験を少し補助。|
|奏斗との分析|選択時の苦手能力を、別々の二走で練習。|ライバルと特訓し、選択時の苦手能力を自主練。|
|岸の応援|フィジカルを練習した後、有効完走。|旋回を練習した後、3着以内で有効完走。|
|折れた航跡|以前の得意能力を練習した後、有効完走。|別の軸の能力を練習した後、有効完走。|

通常の行動枠を使います。体力などの新しい管理数値は追加していません。準備画面に目標と進捗を表示し、達成は各方針の選択につき一度だけ記録します。整備経験やコツの補助は小幅にし、能力・整備力の既存上限を守ります。再起編の実践は、その日の試行であり、既存の「磨き直す／新しい主軸」の大きな方針を強制変更しません。

本編の次の選択で、新しい実践に切り替えます。直前の実践結果は章の本文へ保存されます。育成終了後の最終返答で、実行できない新しい課題を開始することはありません。未達でも物語は進みます。
