# 競艇物語 V124

V123までのシナリオ・GUI改善を引き継ぎ、レース描画、姿勢と揺れ、スタート判定、フィジカルと引き波の関係を更新しました。基本版・Android Safe・iPhone Safe・編集用・素材分離版の全5種類へ反映しています。

## 今回の変更

| 項目 | 変更内容 |
|---|---|
| 水面 | 細かな反射、遠近による波の変化、局所的な白波と航跡を追加 |
| 水しぶき | 艇の航跡・飛沫と、画面下の側面に飛ぶ小粒のしぶきを改善。速度・波に連動 |
| 背景 | 岸壁、観客席の屋根や窓、遠景の霞を追加。雨天にも対応 |
| スタート | 早発が許容されるのはスタート能力B以上。C以下は時刻前のライン通過でF、ちょうどの通過は有効 |
| 引き波 | 低フィジカルほど前方からの引き波を強く受け、後続へもやや強い波を残す。高フィジカルでは両方を軽減 |
| 画面の揺れ | 高速・荒天・引き波で上下と傾きの揺れを強め、高フィジカルほど軽減 |
| 姿勢 | 起こすと高い目線で先を見渡し、伏せると水面へ近づく。目線・画角・傾きの差を拡大 |
| 数値の整理 | 早発許容の秒数、直線能力の換算値、仮成長時の小数値を通常画面から除去。必要な説明は折り畳みのヒントへ |

実際のST・順位・タイム・育成する能力値は残しています。「動き停止」では視点の揺れと動く飛沫を止め、姿勢の見え方は維持します。演出「控えめ／なし」も保持しています。

### バランスとデータの引き継ぎ

引き波の耐性は従来の大きなフィジカル差を縮め、受ける側と発する側の効果をそれぞれ小さな範囲へ調整しました。特殊能力の効果・上限は維持しています。スタートB以上の既存の余裕と、資格を満たす強敵の先行特性は残しています。

旧セーブの選手・物語・賞金・レース位置を引き継ぎます。進行中のレースには新しい走行ルールが適用され、未通過の相手艇のスタート目標も更新します。すでに通過済みのST/F/L判定は書き換えません。

以前のルールで合法だった練習記録は保持します。新しい練習は別条件の履歴となるため、旧ルールの自己ベストとは比較しません。育成や物語の条件・報酬は変更していません。

## 起動ファイル

| ファイル | 用途 |
|---|---|
| `index.html` | 基本版。画像・音源を内蔵 |
| `index_android_safe.html` | Android Safe版 |
| `index_iphone_safe.html` | iPhone Safe版。画面高追従・JSON共有保存の補助付き |
| `index_editable.html` ＋ `src/` | 編集用。フォルダごと使用 |
| `web/index.html` ＋ `web/` 内のファイル | 素材分離版。フォルダごと配信 |

HTMLの実行に対応したブラウザーで開いてください。iPhoneはSafariで配信したURLからの利用を想定します。この配布物に公開URLは付いていません。

セーブキーは `kyotei_monogatari_v80` のままです。更新前に設定画面からJSONを書き出すと、ブラウザーやファイルの場所が変わっても引き継げます。操作練習の比較履歴は別のブラウザー内データで、育成JSONには含まれません。

## 検証の範囲

今回の検証結果は `tests/*v124*.json`、描画画像は `tests/graphics-previews/` に保存しています。

- B/C境界、ゼロ時刻の通過、F/L、強敵、旧レースの再開、発波・受波の単独効果を検証。
- C以下の相手艇を荒天・向かい風・追い風を含む条件で走らせ、スタート失敗の偏りを確認。
- 旧版の練習記録の保持、新ルールとの条件分離、実際の操作練習3種類の終了と比較を検証。
- 数値を抑えた画面のHTML生成、折り畳み、保存復旧、会話進行をDOM代替環境で検証。
- 実Canvasで晴天・雨天・姿勢差と飛沫を描画。WebGLシェーダーはMesa環境でコンパイルとリンクを確認。
- 全5種類のHTML・CSS・ゲーム処理・画像・音源の一致と、基本版・両Safe版の同一条件の進行を検証。

**実ブラウザーのレイアウト、Android／iPhone実機のタッチ・音・FPSは未検証です。** Canvas画像と処理時間は開発環境での結果で、端末上のWebGL画質やFPSを保証するものではありません。旧版の検証JSONは今回の実行結果ではありません。

## 更新する場合

ユーザー指定により、今後も全HTMLを同時に更新します。

1. `src/` と基本 `index.html` のHTML・CSSを変更。
2. `python3 tools/build_all.py` で全5種類を生成し、内容一致を確認。
3. 関連テストを実行し、基本版・両Safe版を含む一式を配布。

過去の更新内容は `README_V123.md`、`README_V122.md`、`README_V121.md`、`README_V120.md`、`CHANGES_AT.md` を参照してください。
