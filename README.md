# 競艇物語 v87 — 育成 × 一人称ボートレース

選手を育て、6艇で600mのコースを反時計回りに3周する、スマホ縦画面向けゲームです。自分で操船する方法と、同じ水面計算をAIに任せる観戦モードを選べます。外部ライブラリ・通信・音声・課金は使いません。

## 起動とファイル

- Android：`index_android_safe.html` をJavaScriptが実行できるブラウザ／HTML実行環境で開きます。
- iPhone：`index_iphone_safe.html` を使用。SafariではWebサーバーに置いたURLから開きます。詳細は `IPHONE_README.md`。
- PC／通常のWeb公開：ZIPを解凍し、同じフォルダ内の `index.html` を開きます。

単体HTMLには全CSS・JavaScriptを埋め込んでいます。ファイルアプリやチャット内のプレビューがJavaScriptを許可しない場合、そのプレビューだけでは遊べません。HTML側でOSの実行制限を解除することはできません。3D描画に失敗した場合はCanvas 2Dの軽量な一人称表示へ切り替えます。Android／iPhoneの実機プレイは未検証です。

## 操作方法

1. 名前、初期能力・成長型、イージー／ノーマルを選んでデビュー。
2. シリーズへ参加し、次走前に練習または機材調整を1回実行。追加能力・券があれば追加できます。
3. 出走表で天候・機材・相手を確認し、ティルトを−0.5°／0°／＋0.5°／＋1.5°／＋3°から選びます。
4. 「自分で操船する」または「観戦モードで進める」を選びます。
5. 操船では「水面へ出る」で12秒の助走を開始。4〜6コースは後方から。12秒針が時計回りに1周して頂点へ戻るとスタートです。
6. 左下半分のどこからでも左右へドラッグして操舵。右手で「加速」を押し続けると速度を維持します。曲がる前に指を離すと水の抵抗で減速します。ブレーキはありません。
7. ブイの外を反時計回りに3周してゴール。賞金・成長を確認して次走へ進みます。

| 操作 | スマホ | PC |
|---|---|---|
| 操舵 | 画面左側・下半分から左右ドラッグ | ← → / A D |
| 加速 | 右の加速ボタンを押す | ↑ / W |
| 減速 | 加速から指を離す | ↑ / Wを離す |
| 一時停止 | 右上のⅡ | Esc |
| 観戦へ切替 | 一時停止メニュー | 同左 |

丸いノブが実際の舵、細い印が指の指定位置です。水圧で舵の可動域と動く速さが制限され、旋回能力が低いと低速でも切り込みが遅れます。全開中に曲がっても自動で速度は落ちません。横滑り、接触、転覆のリスクを見ながらアクセルを抜いてください。速度・風速の表示はkm/hです。

## スタートと復帰

スタート能力は初動のエンジン応答、助走加速、表示する発進目安の精度に反映します。表示は「まだ早い／合わせる頃／遅れ気味」と「読み：粗め／標準／精密」。低能力の目安には保存済みの読み誤差があり、再読込で変わりません。表示に頼り切らず、時計・船首・ラインも確認します。

ゲーム内のFは**0.25秒を超えて早い通過**、Lは**1.5秒以上の遅れ**。ちょうど−0.25秒は許容、＋1.5秒はLです。実際の競技規則より遊びやすくした独自設定です。許容内の早いSTは「0.10秒早い（許容内）」と表示します。F/Lの賞金・予選ポイントは0です。

内側ブイへの接触後、コースに沿ってほぼ動けない状態が0.7秒続くと、自動で船首を外向きに戻します。その場で向きを変え、座標・進行度を移動させず、追加の停止時間も与えません。アクセルで復帰してください。衝突自体による失速と慣性は残します。接触しながら十分に進んでいる場合は発動しません。NPC・観戦の自艇も共通です。

一時停止メニューの通常の「立て直す」は別機能で、同じ進行地点に戻して4秒停止します。転覆・F/Lからは復活できません。制限時間はスタート後270秒です。

## 5能力と整備

| 能力 | 主な役割 |
|---|---|
| 直線 | 最高速と直線の追走力 |
| 旋回 | 低速からの舵の速さ・可動域、旋回角速度、横滑りの収束 |
| スタート | 発進時のエンジン応答・加速、発進目安の精度、再加速応答の一部 |
| 加速 | 減速・接触後の再加速、エンジン応答 |
| フィジカル | 接触時の押し負け、旋回の横流れ、波・傾き、終盤の消耗 |

機材の補正も計算に加えます。v87ではモーターの伸び・機材の加速・プロペラの旋回を強めました。ティルトは高いほど最高速が上がり、グリップと横滑りの収束が低下します。低い角度は速度を抑えて安定を得ます。ティルト変更は無料、次の1走に適用。機材調整はシリーズ中持続し、次シリーズの機材抽選で更新します。

能力と機材の表示は小数切り捨て＋アルファベットランク。小数は内部に蓄積します。能力はS90／A80／B65／C50／D35以上、それ未満E。機材補正は項目ごとの上下限から同じ尺度へ換算します。

## 練習・成長・次走能力

通常練習の固定「次走＋3」を廃止しました。基礎能力の成長と連続調整減衰のリセットは残します。同じ機材の連続調整では調整能力の成長だけ100%→55%→22%へ減衰します。

特殊能力が与える追加行動は、基礎／調整能力の成長と機材効果を50%にします。機材の失敗幅も半分です。通常行動を先に消費し、専用の追加枠を次に使用します。追加券の効果は通常どおりです。能力の発動・追加回数・50%適用を通知とログで示します。

新しい次走専用能力は、そのレース前の最初の練習で一度だけ抽選します。同系統は所持する最上位だけ有効です。追加の練習で引き直すことはできません。発動すれば練習した能力を次の1レースだけ強化し、次走準備で消えます。

| レア度 | 能力名 | 発動率 | 次走補正 |
|---|---|---:|---:|
| N | 水面の予習 | 16% | ＋1 |
| R | 走りの予感 | 25% | ＋2 |
| SR | 集中ルーティン | 38% | ＋3 |
| SSR | 水面との同調 | 52% | ＋5 |
| UR | 一走への研鑽 | 68% | ＋7 |
| LR | 一走入魂 | 82% | ＋9 |

能力が与えた追加枠で最初の練習をした場合、発動時の補正量も半分です。アイテム「集中ドリンク」の次走補正は維持します。

後半の成長について、今回の「20%まで下げる」は**終盤の高能力で従来の20%を下限とする**形で実装しました。60以下の能力は減衰させず、60を超えると段階的に減衰。SGの90以上では20%、SGの75では60%です。新人にはこの減衰を掛けません。弱い能力の育て直しと特化ビルドを残すためです。練習とレース後の基礎成長へ共通適用し、調整能力・機材効果には掛けません。

## 難易度とシリーズ

イージーは勝ちやすさを重視し、基礎・調整能力成長75%、獲得レア度−1、ショップSSRまで、SG優勝UR。ノーマルは成長100%、高レア報酬、SG優勝LRで、NPCが強めです。成長率は上記の後半減衰などと重ねます。賞金条件は共通です。

v87はイージーのNPC・観戦補助係数を維持。ノーマルはNPCの基礎速度を約2.8%、加速を約2.4%上げ、G3以降の追加係数も強めました。観戦の自艇補助をさらに下げています。NPCも同じ舵・接触・引き波・転覆計算を受けます。順位に応じた強制追いつきや、タイムの事後書き換えはありません。

新人前後期→G3前後期→G2前後期→G1前後期→SGの全9シリーズ。各20人、予選5走。得点上位6人は優勝戦、7〜12位は順位決定の準優勝戦、13位以下は敗退。全員が同じ予選出走数になる補完レースを計算します。G1後期終了時の累計賞金1,800万円がSG進出条件です。SG後・進出未達時には購入1回限りの登録前ラストショップがあります。

登録選手・記憶ライバルはSG優勝戦だけに特別参戦。先着時は相手の高レア能力を獲得する機会があります。ノーマルでは対象能力をそのまま獲得、イージーではレア度を1段階下げます。登録選手の6人レースと仮想コインによる応援もあります。舟券購入や実際の金銭取引はありません。

## 特殊能力・ビルド

強化／戦術／妨害／防御／整備／育成／人気／環境／弱点の共通カテゴリを使用。高レア発動のカットインは能力IDを直接保持し、水面・周回表示に重ねます。妨害無効、半反射、完全反射があり、反射を再反射しません。

洞口スペシャル系は1周目強化・2周目補正なし・3周目反動。モンキー系はSR「モンキーターン」、SSR「Vモンキー」、UR「超絶Vモンキー」、LR「究極Vモンキー」。全開・左舵・ターン中の条件を満たすと短時間の旋回を補助します。同系統は最上位だけ有効で、SRの効果は控えめ。接触・ブイ判定は残ります。原作の画像・音声・文章は使用していません。

2つの能力群と必要ステータスで「先手必勝／差し返し／荒水の構え／攻防一体／整備の継走」が成立します。条件に合う場面で強化し、一部性能の代償も設けています。所持能力・ショップのおすすめ理由から連携を確認できます。

## 保存・移行

localStorageに自動保存。使えない環境ではメモリへ退避し、JSONバックアップを使用できます。メモリ保存だけの場合は画面を閉じると失われるため、データ管理から書き出します。iPhone版は共有保存とコピー用JSONに対応します。金額は万円未満を表示せず、10,000万円から億円を併記します。

v86の選手・賞金・機材・登録記録を引き継ぎます。旧版の進行中レースは元の10秒助走のスタート時刻・位置を維持。新規レースから12秒です。旧セッティングは標準→0°／出力重視→＋1.5°／安定重視→−0.5°へ移行。未開始レースの旧練習ボーナスは解除し、すでに走行中ならそのレースの補正を維持します。

## デバッグと今後の拡張

レース一時停止内の「実況・操船デバッグ」で舵の指定と実際の角度、負荷、ティルト、時速、ST、能力ID、接触、引き波、カットイン待機数を確認できます。「カットイン確認」は表示確認用です。レース前の調整デバッグには前後数値・減衰・追加枠の50%倍率を表示します。

開発者向けの主要検証は `node tests/race-v87-tests.cjs`、`node tests/engine-tests.cjs`、`node tests/android-update-tests.cjs`、`node tests/iphone-tests.cjs`。生成後に `python3 tests/static-checks.py` と `python3 tests/iphone-static-checks.py` を実行します。旧版名のテストは当時の仕様を検証するものがあり、全てを現行仕様の合否基準にはしません。

今後はリプレイ、個別練習コース、ティルト別試走比較、会場別AI、セーブの複数スロットを追加できます。詳細なバランス指標と今回の検証範囲は `BALANCE_REPORT.md` を参照してください。
