# 競艇物語 V123

V122を引き継ぎ、シナリオの文章と、会話・育成・出走準備のGUIを改善しました。基本版・Android Safe・iPhone Safe・編集用・素材分離版の全5種類に反映しています。

## シナリオの校閲と改稿

メイン4編、ヒロイン6人、師匠・ライバル、日常・連作・復帰・決勝会話、旧セーブ用のイベントまで確認しました。

- 加筆前後で同じ入店・電話・作業を二度始める描写を整理。
- 食事と出走の前後、電話とメッセージ、修理した持ち物などのつながりを修正。
- 人物ごとの口調を整え、抽象的な総括や説教の繰り返しを、具体的な行動と会話へ置き換え。
- 選択する前に答えが決まってしまう展開を修正し、返答とその後の反応を接続。
- 記録にない敗因、保証されない勝敗や同時出場の断定を避ける表現へ修正。
- 選択肢・結果文・条件案内も、実際の分岐や獲得条件に合わせて整理。

筋書き、人物ID、好感度・能力・報酬の値、分岐条件は維持しています。**過去のセーブに本文・返答が記録済みの場合、その記録は保存当時のまま残ります。** 新たに生成される話や、現行データを参照して表示する場面に改稿が反映されます。

## 見やすさと操作案内

| 場所 | 改善内容 |
|---|---|
| 会話 | 進行バー、話者の役割、「次を読む／読み終える」、返答が後にあることの予告を追加 |
| 返答 | 番号付きの選択肢。選択待ちでは本文に「次」の操作を割り当てず、返答を選ぶことを明示 |
| 会話の中断 | 「中断して戻る」と表示。しおりと、返答を確定せず戻る既存動作を維持 |
| 長文 | 本文・返答を含む領域を縦スクロール可能にし、短い画面では肖像の占有を縮小 |
| 育成ホーム | 次のシリーズへ進むボタンを長い人物・記録パネルより前へ移動 |
| 出走準備 | 「練習・整備→出走表→レース→結果」の現在位置を表示 |
| 行動回数 | 練習・整備専用と、どちらかへ使う共通追加行動を分離。使い切った状態も文章で明示 |
| 練習 | ボタンの数字を「現在値」と表示。矢印に伸びやすさの説明を併記 |
| 行動結果 | 最近の行動ログを折り畳みの外に表示 |
| レース開始 | 操船・観戦・スキップの操作方法と違いを各ボタン内へ表示 |
| メニュー | 現在のメニューを枠・下線・「現在」の文字で表示 |

雨天描画、保存先ごとの復旧、練習比較などV122までの改善も引き継ぎます。レースの物理計算や難易度、経済バランスは変更していません。

## 起動ファイル

| ファイル | 用途 |
|---|---|
| `index.html` | 基本版。画像・音源を内蔵 |
| `index_android_safe.html` | Android Safe版 |
| `index_iphone_safe.html` | iPhone Safe版。画面高追従・JSON共有保存の補助付き |
| `index_editable.html` ＋ `src/` | 編集用。フォルダごと使用 |
| `web/index.html` ＋ `web/` 内のファイル | 素材分離版。フォルダごと配信 |

HTMLの実行に対応したブラウザーで開いてください。iPhoneはSafariで配信したURLからの利用を想定します。この配布物に公開URLは付いていません。

セーブキーは `kyotei_monogatari_v80` のままです。更新前に設定画面からJSONを書き出すと、ブラウザーやファイルの場所が変わっても引き継げます。操作練習の比較履歴は別のブラウザー内データで、育成JSONには含まれません。

## 検証の範囲

V123の結果は `tests/*v123*.json` に保存しています。

- シナリオのデータ構造・分岐条件・数値・IDをV122と比較。
- メインの結果分岐、ヒロイン・師匠の選択、終幕、会話の中断・再開・読了を検証。
- GUIの実際のHTML生成と操作処理をDOM代替環境で実行。残り行動・状態表示・選択待ち・ページ遷移・保存復旧を確認。
- V122の実装で作った進行中セーブから、選手・レース位置・物語を保持して移行することを確認。
- 基本・両Safe版の埋め込みコードを実行し、同じシードで同じレース結果になることを確認。5種類のHTML・CSS・ゲーム処理・画像・音源の一致を検査。

**実ブラウザーのレイアウト・押下領域、Android／iPhone実機でのタッチ・音・FPSは未検証です。** 狭幅・大文字・短い画面用のCSSは静的に確認していますが、実際の表示確認とは区別しています。旧版の検証JSONは今回の実行結果ではありません。

## 更新する場合

ユーザー指定により、今後も全HTMLを同時に更新します。

1. `src/` と基本 `index.html` のHTML・CSSを変更。
2. `python3 tools/build_all.py` で全5種類を生成し、内容一致を確認。
3. 関連テストを実行し、基本版・両Safe版を含む一式を配布。

従来の仕様と検証は `README_V122.md`、`README_V121.md`、`README_V120.md`、`CHANGES_AT.md` を参照してください。
