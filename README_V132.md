# 競艇物語 V132

ヒロイン7人の全70話とメイン4ルートの序章・全9章に、出会いから再会までの経緯、主人公とヒロインの独白、過去の回想を加筆しました。交流の選択肢は台詞・行動のみを表示します。

## 今回の変更

- 約2万7千字を加筆。借りた物を返す、掲載紙を受け取る、同じ買い物道で再会するなど、次に会う理由と連絡の経緯を人物ごとに描写。
- 中盤からはヒロイン側の私的な時間も描き、仕事上の付き合いから、会いたい相手へ変わる気持ちを段階的に表現。
- メイン4ルートは前の章の出来事を受けて進行。父の工房、同期との比較、地元の応援、離脱からの復帰を、それぞれの記憶と現在の独白で描写。実際のレース結果へ戻る時もブリッジを挿入。
- 独白は「心の声」と明記。主人公の独白中にヒロインを「聞き手」として表示しません。履歴でも会話と独白を区別。
- 交流・イベントの選択肢から、好感度や能力などの事前効果表示を削除。選択後の結果と、行動消費・能力計算は従来どおりです。
- 澪の第6話で電話から対面へ移る流れを明示。第7話までに担当変更後の再会が積み重なる経緯も追加。
- 自動会話、第8話の交際、第10話の最優秀シリーズ優勝戦解放、モーター／プロペラ整備、条件付きティルトを維持。
- 旧版で保存済みの本文・選択・報酬は書き換えません。未読のヒロイン章はV132の本文として始まり、旧本文の途中ページを誤用しません。

## 継続する整備と進行

整備はモーター／プロペラの二択。ティルトはモーター整備力B（実効値65）以上、または「熟練の手元」「匠の設計」「継承の工具」「音を聴く整備」の所持中に解放します。対応するMLR版も対象です。−1°〜＋1°を0.5°刻みで変更でき、行動回数を使いません。出走中・終了後は変更できません。

会話は育成開始・レース前後・次節進行などの節目で自動発生します。「中断して戻る」で読んだ位置を保存し、次の進行より先に続きを読みます。選択後の返答も保存し、再読で報酬を重ねません。

## ヒロインの進行

|節目|内容と条件|
|---|---|
|第1〜7話|出会いから、仕事・過去・相手との距離を知るまで。信頼・好感度・育成段階・待ち走数に応じて進行。|
|第8話|告白への返答。受け入れると交際開始。G1前期／後期いずれかの優勝、好感度70以上、信頼60以上などが必要。友人を選ぶ／断る場合は交際せず、その恋愛ルートを終了。|
|第9話|交際後の日常。予定の食い違いや嫉妬、善意の押しつけを二人で扱う。G1後期以降。|
|第10話|最優秀シリーズの優勝戦へ出場する直前に解放。それまでの小物・会話・約束がつながる最終話。予選・選抜戦では解放しない。読了でルート完走と従来のLR伝授。|

通常は2走ごと、G2後期以降に出会った相手とは1走ごとに会えます。第10話だけは優勝戦直前の待ち走数を免除します。8話目で交際した後、優勝戦へ進めなくても交際状態と恋人の後日談は維持します。出会いや成績によっては、育成中に全話を読めない場合があります。

|人物|物語の中心|
|---|---|
|灯|父の図面と自分の仕事、県外研修、会いたい気持ち。工房の外でも会う関係へ。|
|澪|誤報と訂正の責任、取材相手との境界、担当を離れて伝える好意。|
|凪|競技を離れた記憶、看護師の仕事、自分が世話されることへの戸惑い。|
|奏|舞台で止まった経験、小さな試演会、弾かない日にも会いたい相手。|
|紬|店の移転と休日、客を待つ時間から、恋人と約束する時間へ。|
|瑞希|父の名前、古傷、競争心と嫉妬。恋人にも勝ちたい選手同士の関係。|
|なつ|応援の当番、案内会、自分の予定。旗を持っていない日の彼女を知る。|

「折れた航跡」では凪・瑞希・なつに復帰経験を踏まえた会話を追加しています。瑞希の第10話は、同じ優勝戦を走る場合と岸から応援する場合で台詞が変わります。

## ライバルの進行

晴人・蓮・泉・蒼・伊吹を各5話から8話へ拡充しました。順に新人前期、新人後期、G3前期、G3後期、G2前期、G2後期、G1前期、最優秀シリーズで進められます。第8話には親愛度60以上が必要です。

- 晴人：兄との比較、負けた日の苛立ち、練習の約束を破った後の関係。
- 蓮：図面どおりに走れない相手、失敗を消す癖、説明できない勝ち方。
- 泉：怖さを隠す声、急ぎ過ぎた励まし、怖いまま出走する選択。
- 蒼：遅く競技を始めた焦り、練習量への執着、前の職場との距離。
- 伊吹：強い人に見られる息苦しさ、接戦での怒り、生活と勝負の力加減。

技の伝授は第8話で、8回中6回以上の理解・最後の返答・一度以上の対戦先着を満たした時に一度だけ行います。親愛度の低い初期値と、意識して交流するV129の調整を維持しています。

## セーブと再読

保存キーは `kyotei_monogatari_v80` のままです。能力・賞金・機材・親愛度・獲得済みの技・進行中レースを引き継ぎます。

旧ヒロインの0〜5話読了は同じ進行位置、6話読了は新7話読了相当、7話完走は新8話読了相当へ移行します。旧版で交際していた相手・完走実績・LRの権利を維持し、追加した9・10話を進められます。挿入した話を実際に選択したことにはせず、旧選択履歴を別途保持します。登録済み選手の記録は書き換えません。

旧ライバルの読了済み本文・選択ラベル・返答を保存したまま、残りの話へ進めます。旧第5話で獲得済みの技は再授与しません。今回から読んだヒロイン会話は本文も記録に残り、選んだ返答と一緒に読み直せます。書き換わった本文は未読になり、既読スキップが選択肢を勝手に選ぶこともありません。

## 開き方と編集

- index.html：基本版。単体で開けます。

## V132の検証

今回の結果は tests/*-v132.json です。旧番号の結果は過去の検証記録です。

- narrative-v132.cjs：全70話の加筆・両視点・ブリッジ、メイン40章と区切りの保存、選択効果の非表示、実V131セーブの本文維持を確認。
- flow-v132.cjs：実UIをDOMアダプターで実行。自動発生、中断・再開、返答の保存、二重報酬防止、師匠の入門、優勝戦直前の第9→10話、次節進行、ブリッジの分割・履歴、ティルトの境界と所持能力、旧レースを確認。
- routes-v132.cjs：全7人の10話・全5人の8話、交際・親愛度条件・伝授・後日談。
- legacy-v132.cjs：旧セーブ13件の能力・レース・会話記録を引き継ぎ。
- balance-v132.cjs / features-v132.cjs：成長、整備、親愛度、賞金、ハード、MLRを確認。
- safe-sync-v132.cjs：基本・Android・iPhoneの配布インラインコードで、4シナリオ×3難易度×3HTMLの36レースと保存復元を比較。
- resume-v132.cjs：第1〜9話から予選5走を実計算し、優勝戦出場による第10話解放と保存・報酬を確認。

NodeとDOMアダプターによる検証です。この環境ではブラウザー本体を取得できなかったため、実画面の配置、Safari・Android実機のタッチ、音声、FPSは未検証です。梱包は python3 tools/package_v132.py を使用します。
