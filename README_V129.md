# 競艇物語 V129

前回の成長抑制・整備簡略化・4シナリオ固有効果・横画面の小顔表示を引き継ぎ、ハードモードとMLR、既読スキップ、機材性能と親愛度の調整を追加しました。

## 今回の変更

|項目|V129の仕様|

## ハードモード

新しい育成の開始時に選びます。途中で難易度を変更することはできません。

- 全CPUの基礎能力を1ランク上げます。通常CPU、師匠、ライバル、最終戦の特別選手にも適用し、上限はSS120です。既にSSの能力は上限を超えません。
- CPUは他艇の進路を予測し、混雑と引き波を避け、旋回前の減速と走行ラインをより頻繁に見直します。
- プレイヤーの初期基礎能力と通常比の成長倍率は1.2倍。初期特殊能力はSSRを1つだけ付与します。
- プレイヤーも永久能力をSS120まで育てられます。高い能力ほど成長が鈍くなる仕組みは残ります。
- プラス系の全102能力に「極界・～」というMLR版を追加。主能力+50、他の基礎能力+18と大幅な機動補正がレース中に常時働き、元の技の効果も引き継ぎます。発動条件がある技は、条件を満たすと抽選に必ず成功します。複数所持時の補正には上限があります。
- ハードの最優秀優勝戦では、CPUの出場者全員がMLRを1つずつ所持します。
- プレイヤーは「予選2勝」「優勝戦進出」「優勝戦3着以内」「優勝」で各1つ、最大4つ獲得します。進出報酬は決勝前に有効。失格・転覆・棄権による着順では実績報酬を得ません。同じ実績を再集計しても増えません。
- MLRは通常のショップ・ランダム報酬には入りません。

## 前回から引き継ぐ調整

- レース後の基礎成長量を旧版V127の55%にし、E～Cの伸びも抑制。
- 整備の基礎習熟はAまで。54回の通常整備を集中するとA、半々なら各B程度。特殊能力の補正を含めるとSまで。
- B以下の整備力では普段の改善は小さく、まれな会心で上振れ。失敗しても経験は残ります。
- 「灯を継ぐ」は父の教えで整備経験増加。「冷たい勝算」は苦手能力の分析。「沈まない旗」は有効完走の継続で粘り・旋回を補助。「折れた航跡」は完走で走る感覚を回復。本編のG3後期・G2後期で返答すると、各シナリオ固有の技を伝授します。
- 横画面の会話は上部に顔と名前を小さく表示。主人公の返答中は相手を聞き手として表示し、選択肢が出ても残します。

## セーブの引き継ぎ

保存キーは `kyotei_monogatari_v80` のままです。旧版で獲得した能力、機材、賞金、親愛度、物語の返答、進行中のレース位置を維持します。初期値・初期SSR・初期機材抽選の変更は新しく開始する育成・シリーズから適用します。旧版で最優秀の段階へ進み、旧賞金条件1,800万円を達成した選手は出場資格を保ちます。

旧版のレースは保存されたスタート方針を読み込めます。新しいレースから方針選択のない方式を使います。旧版の整備数値や親愛度を読み込み時に引き下げません。

既読スキップ用の本文記録は今回から蓄積します。旧版の読書位置は維持しますが、記録がない本文を未確認のまま既読扱いにはしません。

## 開き方

- `index.html`：基本版。単体で開けます。
- `index_android_safe.html`：Android Safe。単体で開けます。
- `index_iphone_safe.html`：iPhone Safe。単体で開けます。
- `index_editable.html`：`src/`を参照する編集版。

5種類すべてに同じゲーム処理・会話・CSS・素材を反映しています。iPhone用の画面高追従と共有保存補助も維持しています。

## 編集と検証

編集元は `src/` と基本 `index.html`。`python3 tools/build_all.py` で5HTMLを生成し、`python3 tools/verify_all.py` で全50モジュール・HTML・CSS・素材の一致を確認します。`python3 tools/package_v129.py` で検証済み一式を梱包します。

今回の結果は `tests/*-v129.json` に保存しています。旧版番号のレポートは過去の結果です。主な検証は以下です。

- `node tests/features-v129.cjs`：新仕様16項目。
- `node tests/balance-v129.cjs`：成長・整備・物語・旧セーブ14項目。新しい機材抽選で乱数消費が増えるため、成長比較だけは保存したV128の練習直前乱数へ合わせます。
- `node tests/ui-logic-v129.cjs`：実画面生成・操作・既読・親愛度・保存30項目。DOMアダプターを使用。
- `node tests/story-integration-v129.cjs`：人物紹介・終幕・保存の7項目。
- `node tests/hard-races-v129.cjs`：能力値を揃えた8条件で通常AIとハードAIを比較し、MLRを持つ6艇の最優秀優勝戦も2条件で検証。
- `node tests/safe-sync-v129.cjs`：基本版と両Safe版の実際のインラインコードで、4シナリオ×3難易度×3HTMLの36レースと保存復元を比較。

NodeとDOMアダプターによる確認です。実ブラウザーの導入を試みましたが利用可能な実行ファイルを取得できず、実ブラウザーでのレイアウト、実機のタッチ操作・音声・FPSは未検証です。AI比較は少数の固定条件であり、全状況の勝率を保証するものではありません。
