# 競艇物語 V128

成長ペースと整備を見直し、メインシナリオごとの育成・レース効果、横画面の会話用ミニ顔表示を追加しました。V127の恋愛シナリオ、表情、終幕、レース演出を収録しています。

## 今回の変更

- レース後の基礎成長量を従来の55%へ抑制。E〜Cの成長係数も引き下げました。B以上の既存の鈍化は維持しています。
- 整備は「ティルトを整える」「プロペラを整える」の2択。ティルト角と仕上げ方は自動調整です。成功率・調整ムラ・4方向の選択を通常画面から外しました。
- 整備の基礎習熟はA上限。54回の通常整備を同じ方へ集中するとA、半々ならそれぞれB程度。特殊能力の補正込みならSまで届きます。到達は実施回数・物語・追加行動で変わります。
- B以下では通常の機材改善が小さく、まれな「会心の整備」でよい仕上がりを引き出します。手応えが薄くても経験は残ります。追加整備券は経験・効果とも通常の半分です。
- 物語の特色は育成開始時から有効。本編のG3後期・G2後期で返答すると、それぞれ固有の技を習得します。
- 横画面の会話では、話し手の顔と名前を上部に小さく表示。主人公の返答中は相手を「聞き手」と表示します。選択肢を出しても残ります。

|シナリオ|育成・レースでの特色|物語で得る技|
|---|---|---|
|灯を継ぐ|父が整備士。整備経験を積みやすく、工具と音を聞く技で整備力を補正|継承の工具／音を聴く整備|
|冷たい勝算|奏斗がレース後に苦手能力を分析。次走まで対象の練習と本番を後押し|映像の焦点／勝算の組み立て|
|沈まない旗|有効完走の継続で次走の粘り・旋回を支える。応援が育つと体づくりも後押し|帰る岸の声／胸を張る旗|
|折れた航跡|有効完走で感覚を回復。体づくりと再加速を助け、選んだ走り方の練習へつなげる|今の身体の軸／再起の踏み込み|

「有効完走」はフライング・出遅れ・転覆・棄権のない完走です。沈まない旗の継続は不成立時に途切れます。折れた航跡の回復経験は失敗しても失いません。勝率の一律補正や順位に応じた追いつき補助は追加していません。

## セーブの引き継ぎ

保存キーは変更していません。旧版で獲得した能力・機材・賞金・人間関係・読了記録を保持します。読み込み中のレースには新しいシナリオ補正やティルトの減衰を後付けせず、次のレースから適用します。旧版のレース準備画面で新たに整備した場合は、その操作から新しい整備方式になります。

物語の新しい技を読み込みだけで勝手に付与しません。該当する節目以降の未読本編で返答すると、未習得分をまとめて受け取れます。過去の返答や保存済みエンディングは書き換えません。整備の旧数値が現在の基礎上限を超えていても、保存された数値自体は削りません。新しい計算にはA上限を使います。

## 開き方

- `index.html`：基本版。単体で利用できます。
- `index_android_safe.html`：Android Safe。単体で利用できます。
- `index_iphone_safe.html`：iPhone Safe。単体で利用できます。
- `index_editable.html`：`src/`を参照する編集版。
- `web/index.html`：画像・音声を分離した版。`web/`全体を同じ場所に置いてください。

5種類すべてに同じ処理・会話・CSS・素材を反映しています。iPhone用の画面高追従と共有保存補助を維持しています。
