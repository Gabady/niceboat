# 競艇物語 V143

V142を基に、改善案「5：登録後の大会・短編・配布改善」（31〜36）を反映しました。

## 遊び始める場所

- **登録選手の大会**：選手名鑑 → 登録選手の大会。登録選手1人から参加できます。
- **短編育成**：選手作成 → 育成の長さ → 短編。一節の予選2走、進出時は最終戦1走で終了します。
- **物語ごとの育成方針**：準備画面 → 物語の育成方針。適用中の補助・本編の実践・過去の取り組みを確認できます。
- **読みやすさ**：設定・セーブ → 表示・演出 → 会話の行間。標準／ゆったりを選べます。
- **更新**：旧版の設定でJSONを書き出し、新版タイトルの「旧版のセーブを引き継ぐ」から読み込みます。置換前には選手名・進行を確認します。

## 登録後の大会

三水面カップは穏やかな水面・向かい風・横風の3戦。全コース選手権は同じ会場・機材・無風の条件で6戦、全コースを一度ずつ走ります。全コース選手権では進入を固定するため、コースを動かす能力は発動しません。

登録選手を1〜6人選び、1人を操船対象にします。残りは招待CPUで補充。招待選手の基礎能力は選んだ登録選手の平均を基準に上下し、15〜100以内。技能は選んだ選手のうち所持数が最少の人を参考に、SSR以下を最大3個採用します。選んだ登録選手自身は、既得能力・技能をそのまま複製します。

ノーマルの既存物理ルールを使い、手動・観戦・結果スキップに対応します。全員の機材は大会開始時に抽選して固定します。1〜6着に10・8・6・4・2・1点、F・L・転覆・未完走は0点。同点は上位着順の回数、有効完走数で比較し、すべて同じなら同順位です。人間の操作と観戦を同条件の競技成績として統合せず、記録に走行方式を残します。

大会は独立した乱数と選手の複製を使用します。育成中の選手、登録選手の能力・賞金・成績、仮想コインは変わりません。大会途中の走行・得点をセーブJSONに保存し、完成した大会の記録は最新20件。途中終了には確認を挟み、報酬の重複授与はありません。登録選手を削除しても、開始済み大会の複製は維持します。

## 一節の短編

4つの本編の主題に対応した短編を用意しました。

| 主題 | 短編 | 育成で試すこと |
|---|---|---|
| 父の工房 | 一本の赤鉛筆 | 同じ部位を詰める／二つの部位を比べる |
| 奏斗との分析 | 二本の映像 | 自分の課題を追う／相手の視点と比べる |
| 岸の応援 | 帰りの一席 | 走り切る身体／前を狙う旋回 |
| 再起 | 今日の艇に乗る | 以前の武器／別の能力から試す |

導入の選択 → 一走目の振り返り → 一節の結末で構成。途中の会話は結果画面の後、次走の準備で自動発生します。短編用の本文は長編の省略表示ではなく、専用に執筆しました。

予選13位以下なら2走で終了。上位6人は優勝戦、7〜12位は選抜の最終戦（既存UIの「準優勝戦」）へ進みます。短編専用の成長倍率はありません。難易度ごとの既存の成長・機材・覚醒規則を使います。登録時は「短編修了」、途中登録は「短編・途中登録」と区別し、大会にも出場できます。

短編でヒロイン10話や最優秀シリーズは進めません。通常の9シリーズ育成と、8話目の交際・10話目の最優秀シリーズ優勝戦の条件は従来通りです。途中の通常育成を短編へ切り替えることはありません。

## 人物・育成・文章

- 知り合った人物を条件に、人物同士の仕事・休日・生活を描く8場面を追加。既存の日常と合わせ、各節1件まで・既読は保存します。案内図の後日談は前の場面の読了後に発生します。全8本が一度の育成で必ず発生する仕組みではありません。
- 本編4ルートの既存の育成差を、準備画面で具体的に確認できるようにしました。父＝整備経験・仕上がり、奏斗＝苦手分析、紗枝＝有効完走の継続、相馬＝感覚回復と主軸の選択。新しい強化倍率を重ねる変更ではありません。
- 本編で次の方針を選ぶと、前に試した方針・対象能力・達成の有無を記録。途中の課題を勝手に達成へ変えません。選手登録後にも実践記録を読めます。
- 新しい文章は、時と場所のブリッジ、一つの発話に一つの意図、行動で伝わる人物の違いを基準に編集。長文は既存の105文字前後のページ分割を利用し、既存のしおりや既読判定は変更しません。選択肢に好感度・正解・報酬の予告は追加しません。

## 配布と表示負担

- 遊ぶだけなら `kyotei_monogatari_v143_play.zip`。基本版・Android Safe・iPhone Safeと起動案内を同梱し、過去のテスト素材や編集ソースを除いた配布です。
- 編集用の全一式は `kyotei_monogatari_v143.zip`。全5HTML、src、web、検証スクリプトを同梱します。
- すぐ開く場合は `index_android_safe.html` または `index_iphone_safe.html` 単体を利用できます。
- 名鑑の表示を12人ずつに分け、追加表示や検索で全選手へ到達できます。人物画像・音声の追加はありません。設定の行間変更は読み位置に影響しません。
- 端末やブラウザーを変える場合はJSONで引き継いでください。同じ保存キーを保っていますが、ファイルの保存場所によってはブラウザーが別の保存領域として扱います。

## 検証

今回の自動検証は195項目。配布する基本版・Android Safe・iPhone Safeでは各61項目（計183項目）のUI進行検証も実行しました。現行の結果は `tests/*-v143.json` に記録します。大会の得点・同順位・失格・連打・途中保存・再開、短編4ルートの完走・予選敗退・登録、旧セーブ移行、既存のCPU・成長・シナリオ進行を検証します。配布する基本版・両Safe版でも実際のHTML内コードを実行します。

検証はエンジンとDOMアダプターによるものです。実ブラウザーの描画・スマートフォン実機のタッチ・音声・FPSは未検証です。描画速度の実測改善や人間の勝率は保証していません。V142以前の検証記録は過去の履歴です。
